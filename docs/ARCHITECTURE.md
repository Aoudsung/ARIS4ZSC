## Parameter ownership

```text
base_params
  task encoder, task GRU, instantaneous geometry encoder, actor, value
  <- PPO only

latent_params
  transition logits, component embeddings, response emission, decision emission
  <- one response/decision predictive score only
```

The parameter trees and Adam states are separate. Each loss is differentiated
with respect to its own tree only — `ppo_loss` with respect to `base_params`,
`latent_composite_loss` with respect to `latent_params` — so every gradient is
applied to the tree that produced it. Within each outer update the latent
transaction consumes the exact collection-time base tree before PPO commits any
base-policy minibatch update, preserving the CRN continuation estimand.

## Runtime state

`PolicyState` contains only:

- base task carry;
- categorical response belief;
- analytic behavior counts;
- previous legal observation;
- previous ego action;
- episode-start flag.

These six fields constitute the entire deployable recurrent state; privileged
counterfactual observations live only in training-side `AnchorBatch` records.

## Static execution modes

The same `DeltaModel` exposes three static paths:

```text
base-only PPO replay
  compute_latent = false
  execute_adaptation = false

latent estimation / CRN continuation
  compute_latent = true
  execute_adaptation = false

frozen deployment
  compute_latent = true
  execute_adaptation = true
```

This division is a static code boundary: the two boolean flags select the
compiled path at each call. It keeps PPO compilation small and guarantees
that data collection and anchor continuations are generated by the registered
base policy.

## Active source boundary

The active source tree is `src/delta_zsc/` and `experiments/overcooked_v2/`.
`test_delta_unified_repository.py` enforces this boundary on every CI run and
asserts each of the following:

- the nine retired identifiers `pair_comparator`, `separation_margin`,
  `context_dropout`, `capability_consistency_weight`,
  `posterior_decision_weight`, `decision_policy_weight`, `gradient_routing`,
  `decision_regret` and `response_cross_log_likelihood` occur nowhere in
  `src/delta_zsc/*.py`, docstrings included;
- `src/path_c/` and a root `analysis/` directory are absent;
- `experiments/overcooked_v2/*.py` is exactly the registered fifteen-file
  application set;
- no active application contains the string `src.path_c`;
- `pyproject.toml` packages `src.delta_zsc*` alone;
- `.github/workflows/` holds the unified workflow alone;
- `METHOD_VERSION` equals `delta_joint_geometry_interface_decision_exact_voi_v3`.

The complete superseded package, its experiment applications, configurations,
workflow and tests are preserved under `legacy/implementation_v8/` as
historical record, and the test asserts those legacy paths remain readable. The
pinned Official adapter draws its protocol constants from
`src/delta_zsc/config.py`, so the active execution graph is built entirely from
the active namespace.
