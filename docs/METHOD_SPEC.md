# METHOD_SPEC — Unified DELTA-ZSC algorithm

`authoritative: true`

## 1. One factorization

The active method is derived from

\[
p(z_{1:T},y_{1:T},A_{\mathcal S}\mid x_{1:T},r_{1:T},u_{1:T},a_{1:T})
=p(z_1)\prod_t p(z_t\mid z_{t-1})p_\theta(y_t\mid z_t,H_t,a_{t-1})
\prod_{t\in\mathcal S}p_\psi(A_t\mid z_t,x_t,r_t,u_t).
\]

`y_t` is the legal observable teammate response. `A_t` is the sparse CRN
all-action return observation. Both channels share the same latent component;
there is no comparator, separation objective, pseudo-responsibility target,
capability encoder, context dropout, auxiliary actor, or loss-weight table.

## 2. Base task policy

A task encoder masks explicit teammate semantic channels before its recurrent
input. A separate memoryless encoder reads current teammate geometry. The base
actor and value function receive the task carry and current geometry.

`base_params` are optimized by recurrent PPO. Every training rollout and every
counterfactual continuation is generated by this base policy, so PPO remains
on-policy and the decision label is defined around the same continuation
policy.

`history_rnn` disables the partner-history mask as a capacity reference; it is
not part of DELTA.

## 3. Analytic behavior statistics

DELTA maintains four independent Beta(1,1) posteriors over observable rates:
visibility, visible movement, visible inventory occupancy, and visible
inventory change. The model reads posterior means and log precision. These are
exact legal-history functions and require no learned capability loss.

## 4. Latent dynamics and response emission

A trainable row-stochastic transition is

\[
T_{ij}=\operatorname{softmax}(L_i)_j.
\]

The response emission preserves the full 5x5 spatial frame and predicts, for
each component:

- visibility;
- relative position conditional on visibility;
- direction conditional on visibility;
- factorized inventory conditional on visibility;
- inventory change conditional on visibility at both ends.

A complete response is scored under one component before the mixture is
marginalized. Missing conditional factors contribute zero log likelihood; they
do not disable physical-time transition.

## 5. Response-only filter

At an episode start the prior is uniform and no fictitious pre-episode
transition is applied. Otherwise:

\[
\bar b_t=b_{t-1}T,
\qquad
b_t(k)=\frac{\bar b_t(k)p_\theta(y_t\mid k,H_t,a_{t-1})}
{\sum_j\bar b_t(j)p_\theta(y_t\mid j,H_t,a_{t-1})}.
\]

Only this response posterior becomes deployment state. Decision observations
never update it.

## 6. Decision emission

Each component predicts a centered six-action return mean and positive model
variance. Because centered action returns live in a five-dimensional subspace,
DELTA scores them in an orthonormal Helmert contrast basis `B`:

\[
\tilde A=B^TA,
\qquad
\tilde\mu_k=B^T\mu_k.
\]

CRN fit replicas provide a full measurement covariance in the same subspace.
The likelihood is

\[
\tilde A\mid z=k
\sim
\mathcal N(\tilde\mu_k,
B^T\operatorname{diag}(\sigma_k^2)B+\widehat\Sigma_{\rm CRN}).
\]

This retains cross-action common-random-number correlation and avoids treating
centered coordinates as independent.

## 7. One latent predictive objective

Response and decision observations are conditionally independent measurement
channels of the same latent component. Their negative log probabilities are
summed and divided by the actual number of observations:

\[
L_{\rm latent}
=
-\frac{\sum_{t}\log p(y_t\mid H_t)
+\sum_{t\in\mathcal S}\log p(A_t\mid H_t)}
{N_y+N_A}.
\]

There is no tunable relative loss coefficient. `response_only` omits the sparse
decision channel by construction.

### 7.1 Alternating estimator transaction

Let `omega_n` be the base parameter tree that generated rollout `D_n` and CRN
anchors `C_n`. One outer update is ordered as

\[
\Theta_{n+1}=\operatorname{MLE}
(\Theta_n;D_n,C_n,\operatorname{stopgrad}(\omega_n)),
\qquad
\omega_{n+1}=\operatorname{PPO}(\omega_n;D_n).
\]

The latent transaction is committed before PPO changes `omega_n`, so its
decision observation is scored with the same base features and continuation
policy that generated the counterfactual return. PPO replay is statically
base-only and cannot depend on `Theta_{n+1}`. This is one alternating estimator,
not a freeze gate, curriculum, or multi-stage method.

## 8. Analytic passive adaptation

Let

\[
\bar Q_t(a)=\sum_k b_t(k)\mu_k(a).
\]

DELTA solves

\[
\max_\pi\sum_a\pi(a)\bar Q_t(a)
\quad\text{s.t.}\quad
D_{\rm KL}(\pi\Vert\pi_0)\le\delta.
\]

The solution family is

\[
\pi_\eta(a)\propto\pi_0(a)\exp(\bar Q_t(a)/\eta),
\]

with `eta` found by deterministic one-dimensional dual search. There is no
learned adaptation actor or policy-temperature hyperparameter.

## 9. Completed active VOI

### 9.1 Predictive response

For probe action `a`, first propagate the current posterior:

\[
\bar b=b_tT.
\]

The response model defines `p_theta(y | z=k,H_t,a)`. DELTA first sums the
binary visibility outcome exactly. In the visible branch, let `u_s` be a fixed
multidimensional Halton point for relative position, direction and inventory:

\[
\tilde y_{a,k,s}=F^{-1}_{\theta,k,a}(u_s).
\]

When inventory-change is legally observable it is also summed exactly. Thus the
only numerical approximation is the remaining finite multi-categorical
response integral; masked factors are never sampled as if they were evidence.

### 9.2 Exact Bayes update for each outcome

The same outcome is scored under every model component:

\[
b^{a,k,s}_j
=
\frac{\bar b_jp_\theta(y_{a,k,s}\mid z=j,H_t,a)}
{\sum_\ell\bar b_\ell p_\theta(y_{a,k,s}\mid z=\ell,H_t,a)}.
\]

### 9.3 Decision value

For a belief `q`, define

\[
V(q;\mu)=\max_{a'}\sum_jq_j\mu_j(a').
\]

Write `v in {0,1}` for visibility, `m_t` for whether the teammate was
visible before the probe, `e in {0,1}` for inventory-change when `v*m_t=1`, and
`c_s` for the Halton-integrated categorical factors. Define

\[
\Phi(a,k,v,c_s)=
\begin{cases}
V(b^{a,k,v,c_s};\mu^a), & vm_t=0,\\
\sum_{e\in\{0,1\}}p(e\mid k,a,v,c_s)
V(b^{a,k,v,c_s,e};\mu^a), & vm_t=1.
\end{cases}
\]

The Rao-Blackwellized deterministic estimate is

\[
\widehat{\mathrm{VOI}}_S(a)=
\left[
\sum_k\bar b_k\sum_{v\in\{0,1\}}p(v\mid k,a)
\frac1S\sum_{s=1}^S\Phi(a,k,v,c_s)
\right]
-V(\bar b;\mu^a).
\]

Thus source components, visibility, and every legally observed
inventory-change outcome are integrated exactly; only the
position/direction/inventory categorical product uses `S` Halton points.
Masked factors contribute no likelihood and are never sampled as evidence.

`mu^a` may be probe-conditioned. The registered OvercookedV2 model uses the
shared current decision matrix as a local-stationarity surrogate. Consequently
this is a one-response decision-equivalence VOI, not a full long-horizon
Bayes-adaptive value.

The policy uses

\[
Q^{\rm active}(a)=\bar Q_t(a)+\gamma\max(\widehat{\mathrm{VOI}}_S(a),0).
\]

The maximum only removes finite-quadrature negative noise; the unclamped value
is recorded. Expected information gain is recorded separately and is never
added to task value.

### 9.4 Numerical diagnostic

Because the first `S/2` Halton points are a nested prefix of the `S`-point rule,
DELTA reports

\[
e_{\rm quad}(a)=|\widehat{\mathrm{VOI}}_S(a)-
\widehat{\mathrm{VOI}}_{S/2}(a)|.
\]

This value is diagnostic only. It does not gate, shrink, or rescale adaptation.
Formal execution fixes `S=16` as a numerical setting.

## 10. Sparse CRN anchors

At registered rollout states, each of six ego actions is forced and continued
for `H` steps using matched common random numbers. Fit replicas train the
decision emission and estimate measurement covariance; evaluation replicas are
held out for decision diagnostics. Anchors are consumed in the same outer
update and never replayed.

## 11. Static execution paths

- PPO replay: `compute_latent=False`, `execute_adaptation=False`.
- Latent MLE and anchor continuation: `compute_latent=True`,
  `execute_adaptation=False`.
- Deployment/evaluation: `compute_latent=True`, `execute_adaptation=True`.

These are static code paths, not learned gates. They prevent latent/VOI graphs
from entering PPO and ensure all training behavior remains the base policy.

## 12. Method variants and configuration

`history_rnn`, `base`, `response_only`, `delta_passive`, and `delta_active` are
nested comparisons. Only `K`, `H`, and `delta` are scientific method fields.
All artifacts bind the resolved configuration, source identity, partner
manifest lineage, and resource ledger.
