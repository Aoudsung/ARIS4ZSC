# 判决性实验阶梯（探索轨总览，S5 归确认轨）

## 核心原则

超越 SOTA 为唯一核心主线：在 OvercookedV2 benchmark 中超越 SOTA 的 performance 是唯一核心目标，所有中间过程服务于推进该目标，不设拖延性门槛。方法轨（Θ3/V6 端到端 Bayes 协调）是唯一关键路径，理论/诊断轨为并行旁路、无阻塞权。

职责：把候选论点（[THESIS_CANDIDATES](THESIS_CANDIDATES.md)）挂到从便宜到贵的五级实验上。判决性实验的意思是，结果直接决定某个论点成立与否，没有中间状态。
判据格式沿用 legacy [RESEARCH_PIPELINE](../legacy/v44/RESEARCH_PIPELINE.md) 的五阶段制：每级给预算量级、读数、通过或停机判据。
纪律：S1 到 S4 属探索轨，产物一律 `scientific_readout_allowed: false`。S5 属确认轨，冻结纪律以 [FORMAL_EXPERIMENT_PROTOCOL](../FORMAL_EXPERIMENT_PROTOCOL.md) 为准，本文不复制其任何数字。
顶会对齐：基线注册、统计协议与论文表图映射以 [PAPER_STANDARD](PAPER_STANDARD.md) 为准。每级实验完成时同步回填对应表图。

## S1 只读机会面板（判决 Θ1）

- 预算量级：零训练。只用现有官方策略库 checkpoint 与环境复制，延续量级参照 legacy 反事实审计（225 状态 × 128 replica 约 1 亿环境步），本轮按 run-disjoint 要求重配面板。
- 设计：模式侧与伙伴侧训练运行完全分离，每种预定义伙伴类型含多个独立运行。先以平衡任务 seed 的完整回合矩阵估计 `V_Z − V_fix`，再在共同前缀上测状态、历史、历史加类型三级参照。
- 读数：`Γ_compat = V_Z − V_fix`，逐类型模式价值排序的跨运行一致性，冻结映射 `m^dev(z)` 在留出伙伴上的 `V_transfer − V_fix,test`。
- 通过判据：`Γ_compat` 点估计为正且训练运行级重采样区间不跨零，同时迁移值为正。
- 停机判据：`Γ_compat ≈ V_fix`，或机会为正但迁移值为零。两种情况都判 Θ1 死，研究重心转向 Θ5 诊断工具方向。**本停机判据的效力限定为仅对 Θ1**："不再投入方法训练"的效果不外溢到 Θ3/方法轨（2026-08-03 人类复议裁决，见[证据台账](../status/EVIDENCE_LEDGER.md)）。
- 意外发现捕获口：单格回报的伙伴×类型交互结构；某类型内部跨运行排序不稳定但类型间稳定（提示惯例粒度比运行粒度更真实）。

## S2 受控相图任务（判决理论工具，支撑 Θ2）

- 预算量级：小。有限合作任务可精确枚举 Bayes 路由值，无 RL 训练，纯模拟。
- 设计：独立操纵四个因素。错误模式的价值损失 Δ，伙伴证据强度 κ，证据出现时间，不可逆任务事件。对每组参数精确计算 `V_fix/V_state/V_hist/V_HZ/V_full`。
- 读数：分解链序关系是否处处成立；二惯例 TV 精确式是否逐点吻合；`Θ(log(Δ/ε)/κ²)` 的必要与充分历史长度是否匹配；证据晚于有效窗口时是否出现"oracle 有机会、历史路由无净收益"。
- 通过判据：四项全部成立，且拟合出的常数阶可用于 [THEORY_PREDICTIONS](THEORY_PREDICTIONS.md) 的生态外推。
- 停机判据：TV 精确式或历史需求界在受控任务上就失效。理论工具本身不成立，Θ2 直接关闭，理论预测文档降级为纯数学附录。
- 意外发现捕获口：相图中出现理论未预测的相界（例如证据时机与 Δ 的交互效应）。

## S3 单 seed preflight（不判决任何论点，整级降级）

- 定位：整级降级。原"价值排序证书"的内核压缩为 M1 式单 seed preflight 条目，不再是 S5 的前置闸门。
- 预算量级：一次机械跑加 audit-signals，单 seed，预算以官方协议的单跑定义为上限。
- 设计：跑通 V6 全流程，产出信念质量、遗憾校准、梯度契约统计的描述性读数。Preflight 门槛：反事实延续标签在 held-out 延续上的动作排序 Spearman 与预测覆盖率，门槛值在跑之前写入台账。
- 失败处理：preflight 失败只判本载体不可用，换载体（改实现或信念形式），不停止目标；超越 SOTA 的目标不因 preflight 失败而停止。
- 读数：C0 到 C5 只读审计信号，信念后验的伙伴可分性可视化，信念梯度各分量的余弦结构。
- 性质：描述性，不产生任何有效性主张。读数进探索台账。
- 意外发现捕获口：信念维度与伙伴类型的意外对应；某个损失项的梯度长期压制其余项。

## S4 探索性开发矩阵（为 Θ3 与消融铺路）

- 预算量级：2 到 3 个 seed 的 Simple 布局开发矩阵，允许中途改假设。
- 设计：DELTA-ZSC-E2E 对 FCP、OP 参照的同预算 XP 对比，加消融阶梯：PPO-only，加信念，加反事实监督，加 regret shaping。每级须显示 XP 增量，否则该机制在探索轨内标记为拖累嫌疑。
- 读数：XP 均值与 Gap 的开发期估计，消融增量，回收率 ρ̂ 的首次生态读数。
- 通过判据：信念通路消融增量为正，且 XP 不低于最强参照的开发期读数。
- 停机判据：消融显示信念通路净贡献为零或负。Θ3 在确认轨前就地关闭，回探索轨重新选论点。
- 意外发现捕获口：某个布局上信念收益异常大而另一布局上为零（与 THEORY_PREDICTIONS 的布局级预测对照）。

## S5 正式冻结矩阵（判决 Θ3，唯一确认轨级）

- 论点状态：Θ3 复活为方法载体论点（2026-08-03 的传递性门控连带出局被人类复议推翻；依据：传递性门控越界 + S1 个体级读数支持个体推断路线）。S1 停机判据的效力限定为仅对 Θ1。
- 定义：一字不改地引用 [FORMAL_EXPERIMENT_PROTOCOL](../FORMAL_EXPERIMENT_PROTOCOL.md) 的 Official 记分板与共同伙伴记分板，包括 10 seed、Simple 与 Wide 双布局、每格 500 回合、资源台账与 claim boundary。
- 进入条件（晋升门，详见 [TRACKS_AND_GOVERNANCE](TRACKS_AND_GOVERNANCE.md)）：开发矩阵（原 S4）通过，commit 冻结，SOTA 基线数值已注册（见 [SOTA_BASELINE](SOTA_BASELINE.md)）。
- 读数：`J_SP`、`J_XP`、Gap，共同伙伴记分板，完整资源披露。
- 判决：Θ3 成立当且仅当 XP 优于全部注册基线（含 [SOTA_BASELINE](SOTA_BASELINE.md) 注册的已发表 SOTA 数值）且共同伙伴记分板排除内部惯例互利的解释。
- 意外发现捕获口：Wide 与 Simple 的方向不一致；对角 SP 格的异常退化。
