## 一、轨迹采集协议（E2）

- 前缀策略 q：`rnn-sp-seed-0`（Simple 上游 ckpt_final），作为固定 ego。
- 伙伴：Simple 上游全部 20 个 run（sp/op 各 10）。
- 回合数：每伙伴 100 回合（pilot 为 2 回合）；episode key 从正式评估根种子加偏移 1000 派生，与面板 key 流分离。
- 环境契约：Official 协议不动（view size 2、负奖励、随机位置、食谱重采样、400 步）。
- 记录内容（2026-08-03 修订，评审 §7.1）：每回合必须记录 **ego 合法观测历史**（ego 局部观测序列、ego 前一步动作、done 标记，即 Official 部署接口可读的全部信息）、终止步、episode seed；伙伴动作序列（0-5 索引，长 400）继续记录，但**禁止作为主估计口径**，只作 unattainable oracle 参照（见口径声明）。旧口径"不记录 ego 观测原始张量"废止：不记录 ego 合法历史的轨迹不得进入 E3–E5 主估计。
- 观测口径声明（2026-08-03 修订）：主估计口径为 **ego 合法观测历史口径**，与正式部署可读信息一致，用于估计 I(合法 ego 历史; 决策相关协议)。"完整行为口径"（完整伙伴动作序列）给出的是 I(完整伙伴动作 oracle; run/type)，只允许作为 **unattainable oracle 参照**读数并显式标注，**不得**用于生态外推、历史需求计算或理论主张；已基于该口径得出的外推读数须按主口径复核（见 [THEORY_PREDICTIONS](THEORY_PREDICTIONS.md) κ 条目降级声明）。
- 预算：20 × 100 × 400 = 800,000 环境步，4 卡分片。

## 二、Δ 代理定义（E4）

用现有全量面板逐格均值：对每个伙伴 run，取非 identity 模式格的均值，最大减次大记为 Δ_p；Δ̂ 为全体伙伴的均值。登记为代理量，非延续级真值；若 E5 对撞失配且判别指向 Δ，允许一次性升级到同前缀延续测量。

## 三、κ̂(t) 与 TV̂(t) 估计器（E3/E4）

- 口径禁令（2026-08-03，评审 §7.1）：主估计必须基于 ego 合法观测历史；以下首版注册的窗口特征与路由器均以伙伴动作为基底，在口径升级落地前其读数一律降级为 oracle 参照，不进入生态外推。
- 窗口特征：以步 t 为终点、窗宽 w=20 的伙伴动作直方图（6 维），t<20 时用零填充并标注。（2026-08-03 注：首版特征基底为伙伴动作，属被禁主口径；升级基底为 ego 合法观测历史特征，升级先入台账。）
- 分类错误率：两组伙伴的窗口特征用留出式经验 Bayes 分类器（离散特征键的样本频数多数类，留出频数校正；确定性、无超参数）计算错误率 err(t)。首版注册的 1 近邻分类器在 2026-08-03 合成验证中失败（TV̂ 相对偏差最高 1.0），按失配条款换为本口径后重验。
- TV̂(t) = max(0, 1 − 2·err(t))。依据 T2：二分类最小错误率 p_e^* = (1−TV)/2。（2026-08-03 口径限定，评审 §7.3：该式只对最优 Bayes 分类器精确成立；有限样本经验分类器恒有 p̂_e≥p_e^*，故 TV̂ 只作 **TV 下界**使用：1−2p̂_e≤TV，报表须按下界标注，不得当作点估计。）
- κ̂：单步证据强度口径，定义为两组单步边际动作分布的总变差距离，值域 [0,1]。（2026-08-03 降级，评审 §7.2：单步边际 TV 不满足 T3 的 i.i.d. Bernoulli 前提——证据依赖当前环境状态、ego 之前的动作、时间、伙伴 RNN carry 与当前协议，既不独立也不同分布；κ̂ 只作**代理量**，禁止代入 Θ(log(Δ/ε)/κ²) 做历史需求或生态外推；旧表述"与 T3 中 Bernoulli 证据的 κ 同构"作废。）首版误用窗口动作分布 TV（值域随窗宽增长，超限），2026-08-03 修正为本口径。
- 分组定义：类型级为 sp 对 op；个体级为逐伙伴 run 对其余全部 run（19 对 1），报 20 条个体曲线的分布。
- 区间：轨迹级重采样（回合为单元，999 次，固定种子），报 2.5/97.5 分位。

## 四、估计器无偏验证（E3 通过判据）

由 S2 Bernoulli 证据模型生成合成轨迹：已知 κ ∈ {0.1, 0.2, 0.35}、n=64，每组 2000 条序列。过同一估计器，要求：

- TV̂ 相对偏差 ≤ 10%；
- κ̂ 绝对偏差 ≤ 0.05。

不通过则修估计器，不进生态。这是 H2 的第一部分。（2026-08-03 注：S2 合成验证的性质为 theorem unit test，只证明估计器复现其构造时使用的 Bernoulli 参数，不证明生态口径估计同一信息量；见 [THEORY_PREDICTIONS](THEORY_PREDICTIONS.md) S2 降级声明。）

## 五、P4 重定义（已入台账）

测量工具为插入式 Bayes 路由器，零 RL：

1. 后验：给定截至 t 的伙伴动作前缀，与采集轨迹样例做模板匹配（窗口直方图距离），softmax 归一得伙伴 run 后验。（2026-08-03 口径禁令，评审 §7.1：伙伴动作前缀模板匹配属完整伙伴动作 oracle，禁止作为主估计口径；路由器后验必须改为基于 **ego 合法观测历史**，伙伴动作基底读数只作 unattainable oracle 参照；基底切换先入台账。）
2. 模式选择：按面板逐格均值表，选后验期望回报最高的模式 run。
3. 评估：t 时刻共同前缀后强制换到所选模式，共同随机数延续到回合结束，测完整回报。
4. 对撞：实测回收值（路由延续均值减统一模式延续均值）对理论值 D̂_V(t)（legal-history value-weighted distinguishability，D_V(t)=½∫Δ(h)|p₁ᵗ(h)−p₀ᵗ(h)|dh；2026-08-03 由 Δ̂·TV̂(t)/2 改口径，评审 §7.4，"分别平均再相乘"口径废止）。

P4 判据：实测/理论落在 [0.5, 1.5] 内为通过；越界按 THEORY_PREDICTIONS 失配条款处理。P5 形状判据与 P6 布局判据：P5 照原定义用 TV̂(t) 曲线对照（2026-08-03 注：TV̂ 为下界口径，曲线对照按下界读数执行并标注）；P6 本轮只在 Simple 给读数，Wide 后置，结论边界写入台账。

## 六、停机与升级规则

- E4 无停机判据（纯测量）。
- E5 失配且判别指向估计器偏差：允许修估计器重测一次（沿用失配条款）。
- 任何口径升级（ego 合法观测历史基底切换、延续级 Δ）全周期各允许一次，且先入台账。
- （2026-08-03 追加）完整伙伴动作口径在任何轮次都不得恢复为主估计口径；只允许作为 unattainable oracle 参照保留。
