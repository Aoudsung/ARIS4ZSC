# 轨迹采集与信号估计规格（注册版，E1-E5）

状态：探索轨，`scientific_readout_allowed: false`。
职责：注册 Θ2 生态验证（H2/H3）的全部测量协议。本规格变更必须先入[证据台账](../status/EVIDENCE_LEDGER.md)。上游：[THEORY_PREDICTIONS](THEORY_PREDICTIONS.md) 预测表，[S1 面板](S1_EXECUTION_SPEC.md) 数据。

## 一、轨迹采集协议（E2）

- 前缀策略 q：`rnn-sp-seed-0`（Simple 上游 ckpt_final），作为固定 ego。
- 伙伴：Simple 上游全部 20 个 run（sp/op 各 10）。
- 回合数：每伙伴 100 回合（pilot 为 2 回合）；episode key 从正式评估根种子加偏移 1000 派生，与面板 key 流分离。
- 环境契约：Official 协议不动（view size 2、负奖励、随机位置、食谱重采样、400 步）。
- 记录内容：每回合存伙伴动作序列（0-5 索引，长 400）、终止步、episode seed。不记录 ego 观测原始张量。
- 观测口径声明：伙伴动作序列是"完整行为口径"，给出证据强度的上限估计；"ego 可见口径"（仅视野内事件）是后续一次性升级路径，本轮不做。
- 预算：20 × 100 × 400 = 800,000 环境步，4 卡分片。

## 二、Δ 代理定义（E4）

用现有全量面板逐格均值：对每个伙伴 run，取非 identity 模式格的均值，最大减次大记为 Δ_p；Δ̂ 为全体伙伴的均值。登记为代理量，非延续级真值；若 E5 对撞失配且判别指向 Δ，允许一次性升级到同前缀延续测量。

## 三、κ̂(t) 与 TV̂(t) 估计器（E3/E4）

- 窗口特征：以步 t 为终点、窗宽 w=20 的伙伴动作直方图（6 维），t<20 时用零填充并标注。
- 分类错误率：两组伙伴的窗口特征用留出式经验 Bayes 分类器（离散特征键的样本频数多数类，留出频数校正；确定性、无超参数）计算错误率 err(t)。首版注册的 1 近邻分类器在 2026-08-03 合成验证中失败（TV̂ 相对偏差最高 1.0），按失配条款换为本口径后重验。
- TV̂(t) = max(0, 1 − 2·err(t))。依据 T2：二分类最小错误率 p_e^* = (1−TV)/2。
- κ̂(t)：单步口径的同构换算，用窗宽 1 的动作分布错误率代入 κ = 1 − 2·err。
- 分组定义：类型级为 sp 对 op；个体级为逐伙伴 run 对其余全部 run（19 对 1），报 20 条个体曲线的分布。
- 区间：轨迹级重采样（回合为单元，999 次，固定种子），报 2.5/97.5 分位。

## 四、估计器无偏验证（E3 通过判据）

由 S2 Bernoulli 证据模型生成合成轨迹：已知 κ ∈ {0.1, 0.2, 0.35}、n=64，每组 2000 条序列。过同一估计器，要求：

- TV̂ 相对偏差 ≤ 10%；
- κ̂ 绝对偏差 ≤ 0.05。

不通过则修估计器，不进生态。这是 H2 的第一部分。

## 五、P4 重定义（已入台账）

测量工具为插入式 Bayes 路由器，零 RL：

1. 后验：给定截至 t 的伙伴动作前缀，与采集轨迹样例做模板匹配（窗口直方图距离），softmax 归一得伙伴 run 后验。
2. 模式选择：按面板逐格均值表，选后验期望回报最高的模式 run。
3. 评估：t 时刻共同前缀后强制换到所选模式，共同随机数延续到回合结束，测完整回报。
4. 对撞：实测回收值（路由延续均值减统一模式延续均值）对理论值 Δ̂·TV̂(t)/2。

P4 判据：实测/理论落在 [0.5, 1.5] 内为通过；越界按 THEORY_PREDICTIONS 失配条款处理。P5 形状判据与 P6 布局判据：P5 照原定义用 TV̂(t) 曲线对照；P6 本轮只在 Simple 给读数，Wide 后置，结论边界写入台账。

## 六、停机与升级规则

- E4 无停机判据（纯测量）。
- E5 失配且判别指向估计器偏差：允许修估计器重测一次（沿用失配条款）。
- 任何口径升级（可见口径、延续级 Δ）全周期各允许一次，且先入台账。
