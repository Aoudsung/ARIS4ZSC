状态：探索轨产物，`scientific_readout_allowed: false`。
职责：注册"Bernoulli 证据路由任务"的完整规格。实现（`experiments/overcooked_v2/controlled_phase_app.py`）必须与本规格一致；规格变更先入[证据台账](../status/EVIDENCE_LEDGER.md)再改代码。

## 任务定义

单 ego 的有限回合任务，隐藏惯例 z∈{0,1}，等先验。回合长度 H = t_prefix + n_e + 1。

1. **前缀段**（步 1 到 t_prefix）：每步奖励 −c（等待成本），无证据。
2. **证据段**（步 t_prefix+1 到 t_prefix+n_e）：每步观测一个证据位 e_i，e_i 独立同分布于 Bernoulli(p_z)，其中 p_0=(1−κ)/2，p_1=(1+κ)/2。每步奖励 −c。
3. **模式承诺**：ego 可在证据段内任意步 τ 承诺模式 m∈{0,1}（读入截至该步的全部合法历史）。若开启不可逆事件，则承诺截止于 t_lock=t_prefix+n_lock，n_lock≤n_e；到期未承诺强制 m=0。若关闭，截止于证据段末。
4. **终局奖励**：承诺后回合结束，奖励 r(m,z)=Δ·1[m=z]（即 r+=Δ，r−=0）。

## 六控制对象的精确定义

| 对象 | 本任务内的定义 |
|---|---|
| V_fix | 统一承诺任一模式的最优值，等于 Δ/2 减等待成本 |
| V_state | 只用承诺时刻当前证据位 e_τ（不含累积历史）的最优路由值 |
| V_hist(n) | 用全部 n 个证据位的最优路由值，等于 Δ(1+TV_n)/2 减等待成本 |
| V_Z | 给定惯例标签、在同一承诺时刻 n_e 承诺的值，等于 Δ 减统一等待成本 |
| V_HZ | 同 V_Z（本任务标签已含全部惯例信息） |
| V_full | 完整状态含 z 与随机流；本任务终局奖励给定 z,m 后确定，故 V_full=V_HZ |

TV_n 为 Binomial(n,p_0) 与 Binomial(n,p_1) 的总变差距离，用二项概率质量函数精确求和，不做蒙特卡洛。

## 参数扫描网格

| 参数 | 取值 |
|---|---|
| Δ | 2, 4, 8 |
| κ | 0.05, 0.1, 0.2, 0.35, 0.5 |
| n_e | 8, 16, 32 |
| c | 0, 0.05 |
| 不可逆事件 | 关（n_lock=n_e），开（n_lock=n_e/2） |
| ε（T3 目标遗憾） | Δ/8 |

共 3×5×3×2×2 = 180 个参数点。每点输出全部中间量，无随机性，完全可复现。

## 注册检查（每点必须全部通过）

1. **T1 链**：V_fix ≤ V_state ≤ V_hist ≤ V_HZ ≤ V_full，全部在同一承诺时刻 n_e 取值（同付统一等待成本），容差 1e-9。另报 v_hz_free（标签在手即刻承诺的值）供窗口记账使用。
2. **T2 精确式**：`|V_HZ − V_hist − Δ(1−TV_n)/2| ≤ 1e-9` 且 `|V_hist − V_fix_no_wait − Δ·TV_n/2| ≤ 1e-9`（后者扣除等待成本后比较）。
3. **T3 边界**：令 n_emp 为满足遗憾 Δ(1−TV_n)/2 ≤ ε 的最小 n，则 `ceil(log(Δ/(4ε))/(4κ²)) ≤ n_emp ≤ ceil(2log(Δ/ε)/κ²)`。
4. **窗口外无净收益**：在 c=0.05 且证据晚至（t_prefix 大）的配置中，oracle 切换增益 J_HZ − J_sfix > 0，但端到端增益 J_route − J_fix(0) ≤ 0 出现至少一例。此项在扫描外的定向配置（t_prefix=64, c=0.05, Δ=2, κ=0.05, n_e=32）中验证。

任何一点任何一项失败，作业 fail-closed 停机，报告失败点与残差，不自动调参重跑。

## 输出

- 逐参数点 JSON：全部 V 对象、TV_n 序列、n_emp、理论上下界、检查结果。
- 汇总 JSON：四项检查的通过计数与最大残差。
- 论文 Figure 1 数据：Δ × κ 平面上的可恢复价值 `V_hist − V_fix`（等待成本为零的配置）与理论等值线。
