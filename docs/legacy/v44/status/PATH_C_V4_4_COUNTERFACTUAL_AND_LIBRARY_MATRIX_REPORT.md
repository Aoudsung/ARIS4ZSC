# Path C V4.4 反事实任务价值审计与官方策略库交叉矩阵实验报告

- 最后更新：2026-07-29
- 布局：Test Time Simple
- 运行类型：开发诊断
- 科学读数许可：`scientific_readout_allowed: false`

## 技术摘要

两项只读实验给出了相互补充的结论：**固定伙伴面板具有很大的协作回报差异，但 Path C V4.4
当前用于触发回应使用的预测分数没有识别出这些任务价值差异。**

冻结 checkpoint 的反事实任务价值审计恢复第 1,228,800 环境步的 V4.4 seed-100 checkpoint，
对 225 个真实触发状态分别执行 128 组配对延续。预测下界分数的经验覆盖率只有
**29.33%**，低于登记的 95%；预测动作排序与经验动作排序的平均 Spearman 等级相关系数为
**+0.01287**，接近无相关；高预测分数组的经验回应前收益为 **−0.01687**，反而低于低分组的
**+0.00527**。这说明当前主要问题位于动作价值预测、排序及不确定性校准，而不是单次延续
样本不足。

官方策略库交叉矩阵让五个官方最终 checkpoint 分别作为主体，与同一四个冻结伙伴完成
20 个固定角色配对。每个配对 500 回合。单格平均回报从 **−143.80** 到 **+168.12**，跨度
达到 **311.92**；同一 checkpoint 配对均为明显正回报，而不同训练 seed 或训练方法之间存在
大幅正负差异。这证明同一环境和伙伴集合能够产生强烈的任务回报差异，不能把 Path C 的弱
回应效应解释为“固定伙伴面板没有任务杠杆”或“回报几乎不变”。

两项证据共同支持以下裁决：

| 研究问题 | 证据 | 裁决 |
|---|---|---|
| V4.4 是否保留基础协作能力 | 自我配对平均回报 168.48；官方同 checkpoint 配对为 110.00 至 168.12 | 保留能力 |
| 当前预测下界分数是否校准 | 覆盖率 29.33%，登记目标 95% | 未校准 |
| 当前分数是否能排序真实动作价值 | Spearman 相关 +0.01287；高分组经验收益低于低分组 | 未形成有效排序 |
| 固定伙伴面板是否有足够回报差异 | 五乘四矩阵跨度 311.92，每个主体的四配对均值标准差均超过 122 | 有明显差异 |
| 是否应启动十单元正式训练 | 两项预测质量条件未满足，另有两项证据不足 | 继续关闭 |

这两项实验都不是十个独立训练单元构成的标准自我配对与跨策略配对矩阵，不能作为
OvercookedV2 官方 Table 2 指标，也不能形成确认性科学结论。

## 1. 两项实验回答不同但相连的问题

反事实审计回答的是：**在控制器实际触发的状态上，模型声称的回应价值是否能预测通过真实
环境延续得到的任务价值。** 它固定 V4.4 checkpoint，不进行参数更新，并用共同随机数减少
use 与 mask 两个分支之间的随机差异。use 表示吸收登记回应后的信念分支，mask 表示屏蔽该次
回应的信念分支。

官方策略库交叉矩阵回答的是：**同一个 Test Time Simple 环境和同一组四个伙伴，是否能够区分
不同官方策略的协作能力。** 它不使用 Path C 控制动作，只让官方主体按温度 1 分类采样动作。
因此，这个矩阵是固定伙伴诊断的任务基线，而不是 Path C 方法效果的直接估计。

两项实验的关系是：矩阵先确认环境和伙伴组合存在可观测的任务回报差异；反事实审计再检查
Path C 的分数是否找到并利用这些差异。矩阵不能证明 Path C 应当获得多少收益，但可以排除
“所有主体面对该面板都得到近似相同回报”这一解释。

## 2. 冻结 checkpoint 审计显示预测分数没有对应真实任务价值

### 2.1 设计和数据量

审计严格恢复第 1,228,800 环境步的 Orbax checkpoint。它按原 episode seed 和触发步重放，
先核对旧记录中已经保存的动作、预测字段、信念差和三分支最终回报，再接受重建状态。

审计包含两个不同的估计对象：

- **回应前审计：** 固定执行原触发动作，再重新产生回应，用 128 组共同随机数估计 use 减 mask
  的事前期望收益。只有这个量用于检验预测下界分数的覆盖率。
- **回应后审计：** 从回应已经产生、use/mask 信念刚分开的状态开始，分别强制执行六个基础
  动作，再延续至回合结束。这个量用于检验动作价值排序，不冒充回应前期望。

| 审计对象 | 实际数量 |
|---|---:|
| 重建并通过核验的触发状态 | 225 |
| 自我配对 / 固定伙伴触发状态 | 47 / 178 |
| 每个触发状态的重复样本 | 128 |
| 每个触发状态的完整延续行 | 1,792 |
| 完整延续行 | 403,200 |
| 固定伙伴三分支回合行 | 2,000 |
| 审计实际环境步 | 101,149,120 |

每个状态的 1,792 行由回应前 `2 × 128` 行和回应后 `6 × 2 × 128` 行组成。审计完整保存全部
行，没有截断。

### 2.2 总体预测质量

“预测下界分数覆盖率”是经验回应前收益不低于模型预测下界分数的触发状态比例。若分数具有
登记的保守含义，该比例应接近 95%。实际只有 **66/225 = 29.33%**，描述性 Wilson 95% 区间
为 **[23.77%, 35.59%]**。这个区间描述 225 个触发状态的有限样本比例，不代表跨训练单元
不确定性。

| 指标 | 结果 | 解释 |
|---|---:|---|
| 经验覆盖率 | 29.33% | 明显低于登记的 95% |
| 预测与经验动作排序的平均 Spearman 相关 | +0.01287 | 接近无相关 |
| 预测最优动作与经验最优动作一致率 | 21.11% | 六动作随机一致率约为 16.67%，改善很小 |
| 高预测分组经验回应前收益 | −0.01687 | 方向为负 |
| 低预测分组经验回应前收益 | +0.00527 | 高于高分组 |
| 全部状态经验回应前收益 | −0.00585 | 79 正、86 负、60 为零 |

预测最优动作一致率略高于六动作均匀随机的一致率只是描述性对照；动作概率和并列最优会改变
精确随机基线，因此不能把该差值解释为可靠预测能力。更直接的证据是排序相关接近 0，且高分
组的真实收益低于低分组。

### 2.3 分伙伴结果没有形成一致方向

| 来源 | 触发状态 | 经验回应前收益 | 覆盖率 | 动作排序相关 | 最优动作一致率 |
|---|---:|---:|---:|---:|---:|
| 自我配对 | 47 | −0.00040 | 23.40% | +0.0891 | 28.72% |
| Self-Play seed 101 | 37 | +0.00721 | 35.14% | −0.0558 | 12.16% |
| Self-Play seed 102 | 60 | −0.00759 | 18.33% | +0.0715 | 24.17% |
| Other-Play seed 201 | 17 | −0.17992 | 41.18% | −0.0235 | 14.71% |
| Other-Play seed 202 | 64 | +0.03048 | 37.50% | −0.0504 | 19.53% |
| **合计** | **225** | **−0.00585** | **29.33%** | **+0.0129** | **21.11%** |

四个固定伙伴中两个经验收益为正、两个为负。正值不只出现在一个伙伴，但没有跨伙伴一致
方向；各伙伴的排序相关也在正负之间变化。现有证据不支持“预测器只在某一个伙伴类别上已经
可靠”的判断。

### 2.4 回应改变物理轨迹，但很少改变交付

在 201,600 条 use 分支延续中，任务效果分类如下：

| 任务效果 | 延续行 | 占 use 分支延续比例 |
|---|---:|---:|
| 无物理差异 | 126,995 | 62.99% |
| 短暂差异后重新汇合 | 61,543 | 30.53% |
| 阻塞或避让 | 9,866 | 4.89% |
| 交付改变 | 3,196 | 1.59% |

回应分支并非完全没有物理作用，但绝大部分差异没有传播到交付。这进一步限定了问题：既有预测
分数没有把少数真正能改变交付的状态排到高位。

固定伙伴的匹配三分支结果也没有显示稳定正效应。A1 是屏蔽回应时的参照动作，A2-mask 执行
与 use 相同的动作但屏蔽回应，A2-use 执行该动作并使用回应。修正共同随机数后，所有 178 个
触发点的 A1 动作都等于 A2 动作，因此任务成本为 0。

| 固定伙伴 | 触发数 | 回应效应 A2-use − A2-mask | 任务成本 A1 − A2-mask | 净效应 A2-use − A1 |
|---|---:|---:|---:|---:|
| Self-Play seed 101 | 37 | +0.20 | 0 | +0.20 |
| Self-Play seed 102 | 60 | 0.00 | 0 | 0.00 |
| Other-Play seed 201 | 17 | −0.32 | 0 | −0.32 |
| Other-Play seed 202 | 64 | −0.04 | 0 | −0.04 |

全部 2,000 行都满足 `净效应 = 回应效应 − 任务成本`。一个正伙伴、一个零伙伴和两个负伙伴
不能支持可重复正任务收益。

## 3. 官方策略矩阵证明固定伙伴面板具有很大的协作差异

### 3.1 设计和实际预算

五个官方最终 checkpoint 分别作为 `agent_0`，四个固定伙伴作为 `agent_1`，不交换角色。
主体包括 Self-Play seed 100、101、102 和 Other-Play seed 201、202；伙伴包括 Self-Play
seed 101、102 和 Other-Play seed 201、202。Self-Play 指官方自我配对训练，Other-Play 指
官方对称性随机化训练。

每个有向配对严格包含 500 个唯一的 400 步回合。同一伙伴和回合索引在五个主体间使用相同
episode seed。seed 100 的四个格引用旧 `reference_only` 完整原始行；其余 16 个格重新执行。

| 项目 | 数量 |
|---|---:|
| 有向配对 | 20 |
| 完整矩阵回合 | 10,000 |
| 完整矩阵代表的环境步 | 4,000,000 |
| 本次新增回合 | 8,000 |
| 本次新增环境步 | 3,200,000 |
| 新增逐决策行 | 3,200,000 |

矩阵没有训练或更新任何 checkpoint。它只测量官方策略库在同一固定伙伴面板上的任务表现。

### 3.2 五乘四平均原始团队回报

| 官方主体 | Self-Play 101 | Self-Play 102 | Other-Play 201 | Other-Play 202 | 跨四伙伴均值 |
|---|---:|---:|---:|---:|---:|
| Self-Play 100 | 102.56 | 167.88 | −96.84 | −94.32 | **19.82** |
| Self-Play 101 | 113.76 | 81.68 | −99.92 | −124.88 | **−7.34** |
| Self-Play 102 | 46.16 | 168.12 | −105.92 | −118.24 | **−2.47** |
| Other-Play 201 | 15.44 | −90.48 | 166.00 | −123.40 | **−8.11** |
| Other-Play 202 | −71.04 | 85.92 | −143.80 | 110.00 | **−4.73** |

单格平均回报的最大值为 +168.12，最小值为 −143.80。同一 checkpoint 配对分别得到
Self-Play 101 的 +113.76、Self-Play 102 的 +168.12、Other-Play 201 的 +166.00 和
Other-Play 202 的 +110.00，说明五个主体的官方基础能力并未普遍消失。

不同 checkpoint 的配对则高度不稳定。即使训练方法相同，Other-Play 201 与 Other-Play 202
的两个方向分别为 −123.40 和 −143.80；Self-Play 不同 seed 之间既有 +167.88，也有 +46.16。
训练方法不同的配对多数为负，但存在 +15.44 和 +85.92 等例外。因此，决定回报的不是简单的
Self-Play/Other-Play 二分类，而是具体主体—伙伴惯例是否兼容。

### 3.3 聚合均值会掩盖配对结构

| 官方主体 | 2,000 回合平均回报 | 四个配对均值的标准差 | 平均正确交付 | 平均错误交付 |
|---|---:|---:|---:|---:|
| Self-Play 100 | 19.82 | 135.90 | 4.012 | 3.021 |
| Self-Play 101 | −7.34 | 122.44 | 3.218 | 3.585 |
| Self-Play 102 | −2.47 | 136.10 | 3.219 | 3.343 |
| Other-Play 201 | −8.11 | 130.31 | 2.776 | 3.181 |
| Other-Play 202 | −4.73 | 122.63 | 2.999 | 3.235 |

五个主体的跨四伙伴均值集中在 −8.11 到 +19.82，但每个主体的四配对均值标准差都超过 122。
因此，只报告跨伙伴总均值会隐藏比总均值更大的配对差异。三个 Self-Play 主体的描述性均值为
+3.34，两个 Other-Play 主体为 −6.42；主体数只有 3 和 2，不能据此判断训练方法优劣。

## 4. 联合解释：任务差异存在，当前预测器没有找到它

两项实验共同排除了两种过度简化的解释。

第一，结果不是基础能力整体消失。V4.4 checkpoint 的自我配对平均回报为 168.48；官方矩阵
中四个同 checkpoint 配对也得到 +110.00 至 +168.12。主体策略和环境能够完成任务。

第二，结果不是固定伙伴面板回报过于平坦。官方矩阵的单格回报跨度为 311.92，每个主体的
四配对均值标准差超过 122。相同环境 seed 和相同伙伴可以对不同主体产生完全不同的协作结果。

在这两个事实成立的前提下，反事实审计仍得到 29.33% 的覆盖率、接近 0 的动作排序相关和
反向的高低分组收益。因此，当前最有证据支持的根因是：**模型的动作价值预测和不确定性分数
没有正确排序真实任务收益，随后控制器也就无法稳定选择有用回应。**

这个结论仍有限定。官方矩阵使用官方主体，而反事实审计使用适应后的 Path C 主体；矩阵只能
证明该任务和伙伴面板有回报杠杆，不能直接给出 Path C 应达到的收益，也不能单独识别预测
误差来自表示、训练目标、数据覆盖还是部署分布偏移。

## 5. 完整性、稳健性和不确定性边界

两项实验均从完整原始行独立重算，不用运行器摘要生成期望答案。

- 反事实审计的 225 个旧触发点全部通过原 episode seed、触发步、动作、预测字段、信念差和
  旧三分支结果核验；全部 403,200 条延续行完整保存；所有交付计数非负。
- 共同随机数修正后，六个目标测试文件共 69 项通过，0 失败、0 错误、0 跳过。
- 官方矩阵严格包含 20 个配对，每格 500 个唯一回合；同一伙伴下五个主体的 episode seed
  逐项相同；16 份新增逐决策文件共 3,200,000 行。
- 官方矩阵运行前后，旧面板四份回合文件、四份逐决策文件、面板清单、面板元数据和训练身份
  文件的 SHA-256 清单完全一致；原 checkpoint 和旧产物未改写。

两项实验的新增执行预算不能与矩阵代表预算混为一谈。反事实审计实际新增 101,149,120 个
环境步，矩阵新增 3,200,000 个环境步，合计新增 **104,349,120** 个环境步；矩阵另引用了旧
面板已有的 800,000 个环境步，因此两项报告覆盖的证据代表 **105,149,120** 个环境步。

以下限制直接约束结论：

- 反事实审计只有一个 Path C 训练单元，225 个触发状态不是独立训练重复。
- 官方矩阵只有五个官方主体、四个伙伴并固定角色，不是十训练单元标准矩阵。
- 回合级标准误只描述某一固定配对中的回合波动，不能替代跨训练单元标准差。
- 结果相关修订后的 V4.4 运行保持探索性，不能包装成原预登记确认性结果。
- 官方矩阵不能与 Table 2 直接比较，也不能用于解除正式训练门。

## 6. 裁决和下一步

V4.4 已证明三件事：基础策略能力仍在；环境和固定伙伴面板存在明显任务回报杠杆；反事实
延续能够测到动作和交付差异。尚未成立的是最关键的一步：预测下界分数没有覆盖或排序这些
真实任务价值差异。

因此，十单元正式训练继续关闭。不应通过增加训练 seed、延长训练预算、降低策略约束或改用
聚合伙伴均值来绕过该问题。下一项工作应继续使用冻结 checkpoint，直接修正动作价值预测和
不确定性校准，使高预测分状态在同一套反事实审计中稳定对应更高经验回应前收益；在此之前，
官方策略矩阵只作为任务差异基线，不作为方法成功证据。

仍需回答的两个问题是：

1. 预测误差主要来自训练数据覆盖、伙伴分布偏移、槽表示混杂，还是结果预测模型本身；
2. 在不损失 168.48 自我配对能力的前提下，能否让多个固定伙伴同时出现可重复的正回应收益。
