## 候选集

### Θ1 机会本体论

陈述：把模式库与测试伙伴的训练来源彻底分开（run-disjoint）之后，跨独立训练运行仍然存在可重复的兼容性机会，即 `Γ_compat = V_Z − V_fix > 0`，且开发伙伴上冻结的类型到模式映射在完全留出的伙伴上仍产生正的迁移值。

falsifier：run-disjoint 面板上 `V_Z ≈ V_fix`，或 `V_Z > V_fix` 但冻结映射在留出伙伴上 `V_transfer ≈ V_fix,test`。两种观测都直接杀死本论点。

当前证据状态：机会存在性的唯一正信号来自被同 checkpoint 自匹配污染的旧面板，已作废。run-disjoint 机会从未测量。见台账 2026-07-29 三条（119.65 污染、5×4 矩阵、读出 INCONCLUSIVE）。继承 [PATH_C_PROPOSAL](../legacy/v44/design/PATH_C_PROPOSAL.md) 的 H1。

### Θ2 信息时序定理的生态验证

陈述：合法历史在有效切换窗口内可恢复的兼容性价值，由二惯例 TV 界与历史需求 `Θ(log(Δ/ε)/κ²)` 定量决定。在 OvercookedV2 上估计出 Δ、κ、TV 之后，理论能预测路由器学习曲线的拐点步数与回收率曲线的形状。

falsifier：在受控相图任务（S2）中 TV 精确式或历史需求界失效；或生态任务上由估计参数做出的定量预测与实测系统性偏离，且偏离不能用估计协议误差解释。

当前证据状态：受控特例的数学已在 [PATH_C_PROPOSAL §2.3](../legacy/v44/design/PATH_C_PROPOSAL.md) 与 [PATH_C_THEORY](../legacy/v44/design/PATH_C_THEORY.md) 给出，从未做过数值验证，更没有生态外推。

### Θ3 端到端信念协调有效

陈述：V6 的单高斯伙伴信念加信念条件 actor（[绑定设计](../theory/DELTA_ZSC_COMPLETE_THEORY_AND_DESIGN.md) §2-3），在同预算 Official 协议上，XP 均值优于 FCP 与 OP 参照。

falsifier：S5 正式矩阵中 DELTA-ZSC-E2E 的 XP 不高于全部注册基线；或消融阶梯（S4）显示信念通路对 XP 的净贡献不显著为正。

当前证据状态：零。V6 是首次实现候选，只有机械可执行性证据。历史上信念/价值机制两次未学到真实信号（V4.4 Spearman +0.013，读出 INCONCLUSIVE），这是本论点最大的先验不利因素。

状态（2026-08-03 人类复议）：**复活为方法载体论点**。原"随 S1 停机判据连带出局"的裁决被推翻；复议依据：传递性门控越界（S1 停机判据的效力仅限 Θ1）＋ S1 个体级读数（去 identity oracle 84.22）支持个体推断路线。超越 SOTA 为唯一核心目标，本论点是方法轨关键路径。

### Θ4 决策相关性涌现

陈述：伙伴表征只在信念改变动作价值排序的地方变得可分；对回报平坦的伙伴，信念保持不确定。即伙伴建模的涌现以决策相关性为条件。

falsifier：信念表征在决策无关的方向上同样可分（说明学到的只是身份指纹）；或在决策相关方向上不可分（说明机制没工作）。

当前证据状态：与 arXiv:2505.17323 对话，该工作报告伙伴建模仅在适应改善任务表现时涌现。本项目的 decision-regret 与 decision-equivalence 机制（绑定设计 §4-6）提供了可操作版本，但从未做过表征层面的检验。

### Θ5 分解链作为通用诊断

陈述：`V_fix ≤ V_state ≤ V_hist ≤ V_HZ ≤ V_full` 六控制设计可作为任何 ZSC 方法的通用诊断工具，能定位机会、信息、控制三类瓶颈。

falsifier：分解链在实现层面不可估计（例如某一级参照构造不出来），或各级读数之间出现与理论序矛盾的排序且可归因于估计方法而非噪声。

当前证据状态：数学序关系平凡成立，操作化设计见 PATH_C_PROPOSAL §5.4 六控制表，从未完整跑过。

## 顶会准入过滤

四维评估之外，每个候选论点必须过一道顶会准入过滤（标准见 [PAPER_STANDARD](PAPER_STANDARD.md)）：

1. 能支撑主张层级 L3 及以上（有可检验的定量预测或 SOTA 对比），只能支撑 L1/L2 的降为次论点或工具贡献。
2. 与生态位图谱确认的空位有直接对应，不与已占位工作正面撞车。
3. falsifier 有注册的可执行层级：探索轨论点须在 S1 到 S4 预算内可执行；方法载体论点（Θ3）按注册规则由 S5 正式矩阵判决，不受此条限制。

过不了滤的论点直接出局，理由入台账。
