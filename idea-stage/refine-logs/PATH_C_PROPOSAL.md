# 只探查会改变决策的信息
## 面向零样本协作的决策导向伙伴推断

**英文题目：** Probe What Changes the Decision: Decision-Focused Active Partner Inference for Zero-Shot Coordination
**项目线：** Path C
**主基准：** JaxMARL OvercookedV2 Test Time Simple
**预先指定的复现基准：** JaxMARL OvercookedV2 Test Time Wide
**必需第二领域：** Hanabi；只有完成独立领域证据后才提出跨领域主张
**方案定位：** 方法、理论和因果实验围绕同一个问题展开；复杂的表示审计降为支持性分析

> **一句话主张：** 当多个伙伴解释仍与当前历史相容时，智能体应只为那些可能改变后续最优动作的回应付出探查成本，而不应为辨认与控制无关的身份或风格而探查。

---

## 摘要

零样本协作要求一个智能体与训练时未见过的伙伴直接合作。困难通常不在于完整识别“伙伴是谁”，而在于尽快判断哪些尚未确定的伙伴差异会改变下一步控制决策。现有方法大多被动地从历史中推断伙伴，或主动最大化伙伴回应的信息量；后者会同样奖励身份、风格和动作习惯等容易辨认但不改变最优动作的信息，因此可能浪费本就有限的交互机会。

本方案提出**决策导向伙伴推断**。智能体维护四个训练伙伴策略家族形成的伙伴原型，并分别学习两类模型：伙伴在候选任务动作后的可见回应分布，以及与该伙伴家族协作时的动作相对价值。候选探查动作按“观察回应后，预期减少多少控制遗憾”评分，再扣除该动作的即时机会成本。只有净收益为正、预算未耗尽且动作风险不超过预先固定上限时，智能体才执行探查。伙伴回应的广义 Jensen–Shannon 散度只作为“最大化通用回应信息”的对照，不再冒充价值导向目标。

方法把基础任务能力与伙伴适应分开。循环骨干先通过标准自博弈获得做菜能力；伙伴池只接纳来自不同训练运行且达到能力标准的策略。适应阶段中，循环控制表示只接收共享价值评估网络（critic）的时序差分价值梯度。策略头、伙伴回应模型和伙伴条件价值头都只使用截断梯度后的骨干特征；伙伴编号不能通过输出头的训练路由直接塑造共享表示。公开基准主结果只使用官方局部观测。显式输入伙伴上一动作的版本属于信息增强变体，只作次要诊断参照，不承担理论上界。

理论在有限的“先探查、后决策”模型中研究理想的信息价值目标。我们将证明三件事：区分具有相同动作相对价值的伙伴身份不会提高该分数；回应模型和价值模型误差对单次探查选择损失有显式上界；当两个控制类别的回应分布距离为 `κ` 时，把错误决策概率降到 `δ` 所需的独立回应数在最坏情况下为 `Θ(log(1/δ)/κ²)`。上界与下界同阶，说明何时主动探查必要、何时信息本身不足。顺序任务中的注册回应通道是受限控制器实现，不自动继承理想模型的保证，其差距由 H2 和配对回报实验检验。另用一个独立的机会审计夹逼关系，严格区分官方观测可实现的构造性收益、目标控制器类别的最优收益和完整信息保守上界。

实证主检验不是把单个 Path C 数字与论文表格简单并列。每个布局先生成 10 个完全独立的外层训练单元；每个单元独立拥有一个自博弈骨干、两个自博弈伙伴、两个 Other-Play 伙伴、预拟合、校准和随机流。四个条件只在同一单元内共享这些上游对象，再分别适应训练。Test Time Simple 上的平均 cross-play 回报差异是确认性终点；cross-play 指来自不同独立训练单元的最终策略在测试时配对。Test Time Wide 用冻结后的同一方法复现布局方向。来自不同训练算法、目标或约定生成机制的 held-out 伙伴族使用独立评估表，不进入训练支持。Hanabi 检验相同“注册回应通道的增量价值减任务成本”对象能否跨领域成立。已发表的 Self-Play、State-Augmented、Other-Play 和 Fictitious Co-Play 数字只作外部背景；没有原始 checkpoint 或逐 seed 数据时，不声称统计显著优于它们。

## 1. 研究锚点

### 1.1 核心缺口

伙伴推断包含三种不同目标：

1. **身份信息：** 回应能否告诉我伙伴来自哪个训练运行；
2. **行为信息：** 回应能否告诉我伙伴接下来可能做什么；
3. **决策信息：** 回应能否改变主体智能体接下来应当选择的动作。

前两种信息不必然具有控制价值。一个伙伴的移动风格可能极易识别，但所有风格都要求主体智能体做同一个动作。最大化身份可辨识度、回应熵下降或广义 Jensen–Shannon 散度，会在这种情况下产生无用探查。

本项目只把第三种信息作为主要目标。

### 1.2 单一研究问题

> 在伙伴身份和策略参数不可见时，零样本协作智能体能否用少量普通任务动作，主动消除那些会改变后续最优动作的伙伴不确定性，从而提高与未见伙伴的协作回报？

该问题形成一条可检验的因果链：

`候选任务动作 → 伙伴可见回应 → 伙伴信念更新 → 控制遗憾下降 → cross-play 回报提高`。

任何不能进入这条链的理论对象、审计流程或实现细节都不是主贡献。

### 1.3 三个可证伪假设

- **H1，效用：** 在相同骨干、训练预算和评估成本下，决策导向探查提高 Test Time Simple 的平均 cross-play 原始回合回报。
- **H2，特异性：** 当伙伴差异可被回应识别但不改变最优动作时，决策导向方法满足 §6.1 的 5% 探查预算沉默界，且探查率显著低于通用回应信息方法；在匹配的价值相关条件中，它仍提高回报。
- **H3，外部有效性：** 冻结 Simple 上的算法和判定规则后，决策导向探查相对无探查的原始回报增益在 Test Time Wide、预注册的 held-out 伙伴族面板和 Hanabi 三个端点上的预注册 98.5% 单侧下界均高于零。

H1 是主要科学主张。H2 说明收益来自“只购买决策信息”，而不是更强的身份识别。H3 是投稿范围主张：Wide 只是同一基准族内的布局复现，held-out 伙伴族检验生成机制外推，Hanabi 才提供独立领域证据。三项证据不得互相替代。

## 2. 预期贡献与准确定位

### 2.1 三项贡献

1. **决策相关的探查目标。** 用预期控制遗憾下降定义理想信息价值，并给出保留原始官方历史的受限注册回应通道实现；身份细分不变性由理想模型证明，由受控实验检验实现是否继承。
2. **可执行的安全探查方法。** 在任务胜任骨干之上，联合伙伴回应模型、伙伴条件价值头、在线伙伴信念、即时机会成本和固定预算，选择普通任务动作作为探查。
3. **能归因的公开基准证据。** 用匹配训练和配对评估区分骨干能力、伙伴适应和探查控制器的贡献，并用受控正例与身份/风格空结果检验方法是否真的忽略价值无关信息。

### 2.2 与最近方向的差异

| 方向 | 主要解决什么 | 本方案增加什么 |
|---|---|---|
| Other-Play、Fictitious Co-Play 等零样本协作训练 | 通过对称性或伙伴多样性学习更稳健的约定 | 在部署过程中主动决定何时值得辨别伙伴 |
| 伙伴建模与元强化学习 | 从历史被动推断伙伴或任务 | 用真实任务动作主动获取会改变控制的信息 |
| 通用主动系统辨识与价值信息 | 按信息量或预期决策收益选择观测 | 在会改变任务状态的协作动作上，分离“任务进展”与“伙伴回应被使用”的价值 |
| 状态抽象与价值等价 | 描述哪些状态差异对控制无关 | 把该原则变成伙伴探查的选择准则和因果实验 |

伙伴池、循环网络、停止梯度、广义 Jensen–Shannon 散度、时序差分学习以及经典价值信息准则均不是单独的新贡献。[E3T](https://openreview.net/forum?id=6ePsuwXUwf) 已使用伙伴动作预测帮助零样本协作；[Learned Latent Strategies](https://openreview.net/forum?id=M1DA33qucy) 与 [Theory-of-Mind Guided Strategy Adaptation](https://arxiv.org/abs/2602.12458) 已研究在线伙伴推断和策略选择；[DiZCo](https://openreview.net/forum?id=Y47Ab11TjP) 已把伙伴模型与测试时世界模型规划结合。[The Value of Information When Deciding What to Learn](https://openreview.net/forum?id=BR5bZGhzrel) 等工作也已经系统研究“应获取什么信息”。因而本方案不能把“伙伴建模 + 价值信息”本身写成首创。

需要接受查新的新意假设是：**对同一个会改变任务状态的候选动作，成对比较“让注册回应摘要进入专用伙伴信念支路”和“保留原始官方历史与任务转移、但屏蔽该摘要通道”两种受限控制器价值，再相对最佳通道屏蔽动作计算净收益；随后用价值无关伙伴差异和匹配 cross-play 实验检验该分数是否确实减少无用探查。** 如果正式查新发现已有方法同时实现这一评分与同类协作协议，理论和实证必须体现额外差异，否则本项目只能定位为严谨应用。

### 2.3 公开论文的主线与主张层级

论文的公开身份固定为**面向协作决策的信息价值方法**，不再以“涌现伙伴表示”为标题主张。正文按一条因果链组织：先用价值无关身份反例说明通用信息量为何会浪费交互，再给出决策导向分数和受限注册回应通道，随后给出有限模型的不变性、误差和样本复杂度结果，最后依次检验 H1 的任务收益、H2 的价值无关沉默和 H3 的外部有效性。

梯度路由约束解释方法如何避免伙伴编号直接塑造共享表示；表示不变性与身份泄漏检查只负责证伪机制解释。它们不进入论文标题，也不替代回报主结果。R015 是实现前的机会与测量规范，不是论文主要贡献；只有它产生正式正结果时才作为构造性先验证据进入正文，否则只在项目记录或限制部分说明。

公开主张按以下顺序收缩：H1 未通过时，不声称主动探查提高协作；H2 未通过时，不声称方法忽略价值无关身份；H3 任一组成部分未通过时，不声称跨布局、跨伙伴生成机制和跨领域的共同有效性。任何较低层结果都不能由较高层的单个高回报替代。

## 3. 形式化目标

### 3.1 伙伴原型与动作相对价值

令 `h` 为主体智能体按官方协议可见的当前历史。令 `U` 表示所有不属于 `h`、但影响后续回报的完整隐藏状态，包括隐藏环境变量、伙伴原型、伙伴私有观测和伙伴内部记忆。正确的信息状态是

`mu_h(du)=P(U in du | h)`。

令 `θ∈Θ` 为伙伴家族原型。正式 OvercookedV2 实现中的四个坐标分别表示当前适应策略、本单元骨干历史、外来自博弈历史和 Other-Play 历史；具体 checkpoint 只是家族内的训练样本。原型不等同于测试伙伴的真实身份；测试时的概率 `b(θ|h)` 只是 `mu_h` 在家族坐标上的边缘概率，表示“当前伙伴更像哪些训练家族”。在一般顺序任务中，回应概率和动作价值必须对完整 `mu_h` 积分，不能把评估器实际知道的完整状态代入。只有在有限模型明确假设 `U=θ` 时，公式才退化为只对原型求和。

令 `Q_θ(h,u)` 为与原型 `θ` 协作时选择动作 `u` 的 continuation value。定义归一化动作相对价值

`A_θ(h,u)=Q_θ(h,u)−max_v Q_θ(h,v)`。

它消除了与动作无关的整体价值偏移。若两个原型在给定历史下具有相同的 `A_θ(h,·)`，则它们属于同一个**动作相对价值类别**。这是本方案需要保留的伙伴区别；它不是完整身份，也不宣称是唯一语义分解。

### 3.2 当前信念下的控制遗憾

若必须立即选择动作，Bayes 动作为

`u_b=argmax_u Σ_θ b(θ|h)Q_θ(h,u)`。

相对于知道伙伴原型后的动作，当前信念造成的控制遗憾为

`R(b,h)=Σ_θ b(θ|h)max_u Q_θ(h,u)−max_u Σ_θ b(θ|h)Q_θ(h,u)`。

`R(b,h)=0` 表示当前剩余的伙伴不确定性不会改变最优动作；此时没有理由仅为辨认身份而探查。

### 3.3 决策相关信息价值

先考虑有限的“先探查、后决策”模型，其中完整隐藏状态退化为伙伴原型。候选探查 `p` 产生可见回应 `Y`，其伙伴条件分布为 `P_θ(Y|h,p)`，并付出成本 `c(h,p)`。观察 `Y` 后更新信念为 `b^Y`。探查分数定义为

`S(p|h,b)=R(b,h)−E_Y[R(b^Y,h)]−c(h,p)`。

等价地，使用归一化动作相对价值时，

`S(p|h,b)=Σ_y max_u Σ_θ b_θP_θ(y|h,p)A_θ(h,u)−max_u Σ_θ b_θA_θ(h,u)−c(h,p)`。

该式直接连接“回应区分了什么”与“区分后能否选到更好的动作”。相比之下，概率加权的广义 Jensen–Shannon 散度等于伙伴原型与回应之间的互信息；它会奖励全部可辨识身份信息，因此只作通用回应信息基线。

### 3.4 会改变任务状态的探查动作

OvercookedV2 中没有脱离任务的免费询问动作。探查是长度不超过预先固定上限的普通任务动作或短脚本，它既改变世界，也产生伙伴回应。若只给回应信息量加分，再用一个独立价值评估网络粗略扣成本，普通任务进展可能被误记成“伙伴信息价值”。因此顺序任务使用成对的**注册回应通道对照**：固定同一个候选动作、原始官方历史和任务转移，只改变当前候选产生的注册回应摘要是否进入专用伙伴信念更新支路。

候选动作 `p` 结束后的规范化序列记为 `h^+`。冻结字段投影 `P_mask^(p,t)`，从序列化输入中删除本次候选窗口生成的注册回应摘要坐标，以及显式复制、重编码或依赖该坐标的所有非官方派生字段与循环状态写入；原始官方局部观测、主体动作、回报和回合边界不被改写。其他派生字段只有在冻结依赖图确认其不携带当前回应摘要的显式别名后才能保留。定义 `x=P_mask^(p,t)(h^+)`、`y=Y^(p,t)(h^+)`。`y` 在观察后是历史的确定函数，但在执行 `p` 前仍是随机结果；主动探查的价值来自这项事前不确定性。屏蔽组的信念接口、共享延续控制器和循环状态都只能接收 `x`，使用组只多出通往信念接口的 `y`；后续新产生的被动回应对两组相同。由于原始观测仍在 `x` 中，无约束最优控制器不会从可重建的 `y` 获得额外信息，但有限的冻结信念接口仍可能因显式摘要而改变行为。

完整一步模型由

`P(dx,dy,du'|h,p)=∫K_p(dx,dy,du'|u)mu_h(du)`

给出。令 `B_use(mu_h,x,y)` 和 `B_mask(mu_h,x)` 是预先冻结的两个信念更新接口，令 `C(mu,x)` 是共享的冻结延续控制器。两条支路都保留原始官方历史 `x`，唯一接口差异是前者额外接收注册回应摘要 `y`。候选动作的两个受限控制器价值为

`J_use(p)=E[r_p+G(U',x,C(B_use(mu_h,x,y),x)) | h,p]`，

`J_mask(p)=E[r_p+G(U',x,C(B_mask(mu_h,x),x)) | h,p]`，

其中期望对完整隐藏状态、`x`、`y` 和未来随机性积分，`G` 是冻结延续规则的剩余原始回报。这里不能再写无约束条件期望中的 `max_u`：当 `y` 可以从完整 `x` 确定恢复时，无约束最优控制器会使 `y` 严格冗余。上述差值刻画的是显式摘要接口对冻结控制器的帮助，而不是删除全部伙伴行为证据后的总信息价值。

两者之差 `I_response(p)=J_use(p)−J_mask(p)` 衡量显式注册回应通道对该控制器的增量决策价值。由于原始官方历史 `x` 仍被保留，该量不等于删除全部伙伴行为证据后的总信息价值；如果 `x` 可以确定重建 `y`，不受架构限制的最优控制器不会从 `y` 获得新信息。为防止另一个普通任务脚本本来就能取得的收益被漏掉，回应屏蔽参照必须拥有相同候选集合。令

`V_mask(h)=max{V_base(h), max_{p' in P_safe(h)} J_mask(p')}`。

候选动作相对最佳回应屏蔽动作的机会成本为

`C_task(p)=V_mask(h)−J_mask(p)`。

顺序任务主分数是

`S_seq(p)=I_response(p)−C_task(p)=J_use(p)−V_mask(h)`。

只有 `S_seq(p)` 严格超过冻结阈值、回合预算未耗尽、仍在允许探查的早期窗口内且候选动作不同于策略原本动作时，才执行该候选。决策导向阈值固定为禁止实际探查的校准分数空分布第 95 百分位与零的较大者，因此任何净值不为正的候选都不得触发。§3.3 的有限模型是 `x` 退化且探查只产出回应时的特例。

在 R015 和不重新训练的部署配对中，`A1` 表示按 `V_mask` 行动的注册通道屏蔽参照，`A2-mask` 表示执行由 `S_seq` 选出的同一候选但屏蔽注册通道，`A2-use` 表示执行该候选并启用注册通道。以完整回合原始回报 `V` 定义

`Delta_response=E[V(A2-use)−V(A2-mask)]`，

`Delta_cost=E[V(A1)−V(A2-mask)]`，

`Delta_net=E[V(A2-use)−V(A1)]`。

三者满足恒等式 `Delta_net=Delta_response−Delta_cost`。这是回合级实验端点；候选层的 `I_response`、`C_task` 和 `S_seq` 是控制器内部评分，二者不能混作同一种样本。

该分数需要伙伴条件的一步转移—回应模型和可对假设下一历史求值的伙伴条件价值头；当前仅预测下一回应的实现还不够。有限模型理论也不自动证明神经近似规划正确，该问题由公开基准的匹配实验决定。

## 4. 方法设计

### 4.1 基础能力与伙伴多样性先行

Path C 不再要求一个尚未学会做菜的价值学习器同时发现伙伴结构。每个训练单元先训练循环 Independent Proximal Policy Optimization；这里的 Independent Proximal Policy Optimization 指不使用集中式价值评估网络、由各智能体的局部轨迹训练策略的近端策略优化方法。骨干使用官方局部观测和训练配方获得基本任务能力。

正式 OvercookedV2 实现把由共同训练来源和协作角色定义的策略集合称为**伙伴家族原型**。一个具体 checkpoint 只是家族成员，不再单独占据一个信念坐标。四个家族在每个适应阶段回合中各占 25%：

1. 当前适应策略家族：每个 400 步轨迹开始时冻结当时的完整策略作为伙伴；该伙伴独立维护控制器、循环状态、信念、预算和随机数，不接收梯度；
2. 本单元骨干历史家族：本单元自博弈骨干的三个固定训练进度 checkpoint；
3. 外来自博弈历史家族：两个独立自博弈运行各自的三个固定训练进度 checkpoint；
4. Other-Play 历史家族：两个独立 Other-Play 运行各自的三个固定训练进度 checkpoint。

每个官方运行只按训练更新进度机械保存三个 checkpoint，不读取回报选择快照。2026-07-25
结果知情修订前，最终 checkpoint 还承担不低于 100 分的能力筛选；50 个 Test Time Simple
上游运行全部完成后有 3 个固定运行低于该门槛。为避免根据训练结果删除、替换或反复训练
seed，项目负责人明确授权把该门槛改为只报告、不筛选：全部固定 seed、最终 checkpoint
以及机械保存的早期和中期 checkpoint 均进入原定训练单元，报告继续逐项记录阈值是否通过，
但不得影响群体成员资格。该修订发生在新版 Path C 预拟合和适应之前，但发生在 Simple
上游回报已经可见之后，因此修订后的 Simple 和随后冻结执行的 Wide 均标记为结果知情的
探索性实验，不包装为原始确认性预登记。抽样先在四个家族间均匀选择，再在家族内均匀轮换
成员，因此成员较多的家族不会获得额外权重。预拟合、训练校准和适应使用与条件名称无关的

checkpoint 历史用于覆盖不同能力阶段，但不被解释为新的伙伴族。self-play 指同一外层训练单元的最终策略与自身配对，cross-play 指不同外层训练单元的最终策略配对；训练历史成员不得进入正式 self-play 或 cross-play 矩阵。

用于回应模型、价值模型、过滤器支持、校准或方法选择的伙伴属于开发支持。held-out 伙伴族按完整训练生成机制与开发支持不相交；其任何成员都不得进入上述环节。支持内不同 seed 与 held-out 伙伴族是两个不同概念，不能互换。

### 4.2 适应网络

每个适应系统包含四部分。行动策略头也称为 actor：

- **循环控制骨干：** 编码官方局部观测、主体智能体自身上一动作、原始回报和回合边界；
- **共享 actor：** 在截断梯度的骨干特征上用策略梯度更新；
- **伙伴条件价值头：** 每个伙伴家族原型一个输出头，用该家族产生的轨迹做时序差分更新；输入骨干特征在这里截断梯度；
- **伙伴条件回应头：** 每个伙伴家族原型一个回应分布模型，在截断梯度的骨干特征上训练，不向共享骨干反传。

因此准确的方法约束是：**循环表示只接收共享 critic 的时序差分价值梯度；系统整体并非单一时序差分损失。** 伙伴条件价值头虽然也使用时序差分目标，但其按原型路由的梯度不能进入共享骨干。该约束只控制梯度来源，不证明骨干绝对不含身份信息；价值无关条件中的实验负责检验是否仍出现身份细分。

家族编号只用于把训练回合路由到相应的价值头和回应头；家族内 checkpoint 成员编号只用于平衡抽样和审计。两种编号都不能进入骨干、actor 或测试时观测。测试时维护的是对四个训练家族的软概率，不假装恢复真实伙伴身份。

### 4.3 官方观测版本与信息增强版本

公开主结果只使用官方局部观测能够导出的回应，例如可见的伙伴位置变化、交互结果和“当前不可见”标记。显式加入伙伴上一原始动作的版本标为 **action-augmented**，即“额外提供伙伴动作的信息增强版本”；它只作信息更丰富的诊断参照，不与普通输入协议的已发表结果无标记并列，也不承担 §5.4 的完整信息上界。

### 4.4 响应拟合与阈值校准

正式适应前，用独立预算只拟合回应头和伙伴条件价值头；骨干与 actor 冻结。随后运行 500 个禁止实际探查的**训练校准**回合，记录候选分数、即时机会成本和安全候选覆盖率，并冻结适应阶段使用的阈值。适应结束后，每个条件再独立运行 500 个禁止实际探查的**部署校准**回合；正式评估只读取最终适应 checkpoint 及其部署校准，不读取训练校准。

两次校准都使用同一冻结规则。决策导向阈值取 `max(0, q0.95)`，其中 `q0.95` 是相应校准空分布的非插值最近秩分位数；通用回应信息对照继续使用自身空分布的 `q0.80`。随机安全探查的触发概率等于校准决策分数严格超过决策导向最终阈值的实际比例。该规则控制空分布误触发，不手填旧量纲的常数，也不强制产生固定比例的探查。

若校准表明几乎不存在安全且会改变动作的候选，项目应报告“当前候选集、过滤器和控制器没有找到可用探查机会”，而不是继续降低阈值直到产生探查；没有完整信息保守上界时，不把它扩大为整个基底无机会。

### 4.5 计算预算

每个最终系统分别报告：

- 伙伴骨干形成的环境步和 GPU 时间；
- 回应与价值头预拟合预算；
- 训练校准和部署校准回合；
- Path C 适应环境步；
- 评估环境步、延迟和实际探查次数。

当前实现对每个官方上游运行使用约 30M 环境步，对每个外层训练单元使用 1M 环境步预拟合和 500 个训练校准回合，对每个条件使用 10M 环境步适应和 500 个部署校准回合。伙伴池中的五个独立官方运行及其完整训练成本不得隐藏在“每 seed 30M”的表述中。

## 5. 理论目标与保证范围

### 5.1 命题一：价值无关身份细分不变性

把任一伙伴原型拆成若干具有相同归一化动作相对价值的子身份，并保持这些子身份的总先验质量及其混合回应分布不变，则 `S(p|h,b)` 对所有探查 `p` 不变。

**理由：** 分数只通过每个动作相对价值类别的总概率质量及类别与回应的联合分布进入。类内重新命名或细分不会改变两个 `max` 项。若回应只能区分类内身份而不能改变类别概率，预期遗憾下降严格为零，剩余分数只有负的探查成本。

该命题给出理想信息价值目标与通用回应信息最大化之间最直接的区别。顺序任务中的 `S_seq` 只有在 `B_use`、`B_mask` 和延续控制器对价值等价的身份细分保持不变时才继承该命题；当前不把这一性质当作神经实现定理，而由 H2 的受控价值无关条件直接检验。

### 5.2 命题二：模型误差到探查选择损失

条件于一个固定且正确的当前信念 `b(θ|h)` 和精确探查成本 `c(h,p)`，假设归一化动作相对价值有界于 `[-B,0]`，对所有原型和动作有

`|Â_θ(h,u)−A_θ(h,u)|≤ε`，

且每个伙伴条件回应模型与真实分布的总变差距离（total variation distance）不超过 `ρ`；总变差距离指两个概率分布最大事件概率差。则 §3.3 有限模型中任一探查分数的绝对误差不超过

`2ε+2Bρ`。

若使用估计分数选择最优探查，其真实分数相对最优探查的损失不超过

`4ε+4Bρ`。

**证明要点：** `max` 对输入向量是 1-Lipschitz，也就是输入最大改变量为 `d` 时输出改变量不超过 `d`；所有回应的联合概率质量求和为 1，因此价值误差对观察前、观察后两项各贡献至多 `ε`；回应分布的 `L1` 误差是总变差距离的两倍，乘以价值范围后贡献至多 `2Bρ`。经验最优项与真实最优项各再贡献一次统一分数误差，得到第二个界。

该结果是单步条件性保证，不声称神经网络必然达到 `ε` 或 `ρ`，也不控制由多步错误回应模型造成的累计信念偏差。若使用估计信念或估计成本，必须另加入对应误差项。

### 5.3 定理三：达到目标决策错误率所需的回应样本复杂度

考虑两个等先验伙伴价值类别、两个互斥最优动作，选错动作损失为 `Δ>0`。一个探查产生 Bernoulli 回应，两类伙伴的回应参数分别为 `1/2−κ/2` 和 `1/2+κ/2`，因而总变差距离为 `κ≤1/2`。

要把错误动作概率降到 `δ≤1/8`，任何只基于该固定探查的条件独立回应进行判断的方法在最坏情况下都需要

`n=Ω(log(1/δ)/κ²)`

个条件独立回应；似然比检验使用

`n=O(log(1/δ)/κ²)`

个回应即可达到该错误率。因此样本复杂度为

`Θ(log(1/δ)/κ²)`。

**下界：** 两个 Bernoulli 分布每次观测的 Kullback–Leibler divergence 为 `κlog((1+κ)/(1−κ))≤4κ²`。Bretagnolle–Huber 二点检验界给出错误率至少为 `exp(−4nκ²)/4`，反解得到 `n≥log(1/(4δ))/(4κ²)`。
**上界：** 对回应均值在 `1/2` 处做阈值检验，Hoeffding 不等式给出错误率至多 `exp(−nκ²/2)`，反解得到同阶上界。

该定理说明达到指定错误率需要多少信息，不证明理性控制器必须购买这些信息。若 `κ` 很小、价值损失 `Δ` 很低，或累计探查成本高于可避免的预期损失，最优控制器可以选择不探查。

### 5.4 命题四：相对冻结回应屏蔽参照的机会夹逼

令 `pi_ref` 为冻结的回应屏蔽参照控制器。它拥有与探查控制器相同的任务动作、候选脚本、窗口、预算、规划器和原始官方历史，但不把当前候选产生的注册回应摘要送入专用伙伴信念更新支路。令 `Pi_obs` 为所有遵守相同约束且动作只依赖主体可见历史的控制器，定义

`Delta_class_star = sup_{pi in Pi_obs} J(pi) - J(pi_ref)`。

若一个显式控制器 `pi_L` 只使用主体可见历史，则

`Delta_L = J(pi_L) - J(pi_ref) <= Delta_class_star`。

再令 `Pi_full` 为可额外观察完整隐藏状态 `U`、其余动作与约束不变的控制器类别。因为任何主体可见控制器都可以在 `Pi_full` 中忽略额外信息，所以 `Pi_obs` 包含于 `Pi_full`。若 `J_full_upper` 是 `sup_{pi in Pi_full} J(pi)` 的已证明上界，则

`Delta_class_star <= J_full_upper - J(pi_ref) = Delta_U`。

因此

`Delta_L <= Delta_class_star <= Delta_U`。

左侧是构造性下界：一个符合官方观测协议的控制器确实取得了该收益。右侧只有在完整信息最优值被精确求出，或规划误差已有证明上界时才成立。被告知伙伴身份但仍使用有限前瞻、有限蒙特卡洛的固定控制器只是诊断，不是 `Delta_U`。

该命题不依赖学习器逼近误差。R015 的学习器非主张、回应使用配对和统计判定见 [PATH_C_OPPORTUNITY_AUDIT_SPEC.md](PATH_C_OPPORTUNITY_AUDIT_SPEC.md)。

### 5.5 旧表示审计理论的角色

原方案关于“已实现隐藏状态下的回应分布”与“信念平均回应分布”的区分仍然正确且有用：固定单个 checkpoint 的多次未来分支续演只能估计该已实现隐藏状态下的回应分布；要估计给定历史后的信念平均分布，必须独立重采样完整隐藏状态。

但这套结果只用于可枚举、可重置的合成审计。它不直接证明官方 OvercookedV2 中的神经表示恢复了某个真实商空间，也不阻止读取标准 cross-play 性能。完整推导保留在 `PATH_C_THEORY.md`，在更新其主张范围前不得把它写成公开基准的机制证明。

## 6. 实验设计

### 6.1 实验一：受控正例、空结果与样本复杂度

构造一个有限合作任务，交叉控制两条轴：

- 伙伴回应是否容易区分；
- 伙伴差异是否改变主体智能体的最优动作。

四个条件保持回应熵、轨迹长度、动作支持和单伙伴任务难度尽量一致。关键比较是：

- 回应可区分且价值相关：决策导向方法与通用信息方法都可以探查；
- 回应可区分但价值无关：通用信息方法仍会探查，决策导向方法应保持沉默；
- 回应难区分但价值相关：观察探查数是否按 `1/κ²` 增长；
- 回应难区分且价值无关：所有理性方法都不应付出成本。

该实验使用真值动作相对价值和真值回应分布核对分数、误差界及匹配样本复杂度，不用神经网络失败替代理论检验。

H2 使用“实际探查次数除以该回合允许的最大探查次数”作为归一化探查率，取实际沉默容差 `epsilon_probe=0.05`，也就是平均使用不超过 5% 的可用探查预算。为防止一个从不探查的方法轻易通过，H2 同时要求三个单侧条件：

1. 在“回应可区分但价值无关”条件中，决策导向探查率的置信上界低于 `epsilon_probe`；
2. 同一条件中，通用回应信息方法减决策导向方法的探查率差的置信下界高于 `epsilon_probe`；
3. 在匹配的“回应可区分且价值相关”条件中，决策导向方法减无探查的原始回报差的置信下界高于零。

三项各使用单侧错误率 `0.05/3`，只有同时成立才支持 H2。独立生成的伙伴身份组是主要重采样单位，同一身份组内的 episode 不能冒充独立重复；身份组数和每组 episode 数由看不到结果的联合功效模拟冻结。

### 6.2 实验二：Test Time Simple 确认性实验

每个布局构造 10 个彼此独立的**外层训练单元**。每个外层单元拥有自己独立训练的骨干和伙伴池，不与其他外层单元共享 checkpoint、轨迹或随机数。伙伴池至少由两个独立训练运行形成。

本项目的固定实现把每个伙伴池具体化为当前适应策略、本单元骨干历史、两个独立外来自博弈运行的历史和两个独立 Other-Play 运行的历史。因此每个布局在 Path C 训练开始前需要 10 个骨干与 40 个外来训练伙伴，共 50 个互不复用的官方上游运行；每个运行机械提供三个固定进度 checkpoint。四个条件只在同一外层单元内部共享官方来源、checkpoint 历史、预拟合和训练校准；适应及部署校准按条件独立。任何跨单元共享都会破坏 cross-play 的独立训练语义。

官方 `10×9` cross-play 矩阵检验同一训练生成机制下的跨 seed 协作，不自动构成跨伙伴族外推。另建立预注册的 held-out 伙伴族面板：至少两个未参与模型拟合、过滤器支持、校准、阈值选择或方法选择的生成机制，每个机制提供至少四个独立伙伴策略。生成机制可以改变训练算法、训练目标或约定生成规则，但每个伙伴仍须通过同一任务能力下限。该面板在方法和阈值完全冻结后只评估一次。

从每个外层单元同一个合格骨干 checkpoint 出发，复制并独立训练四个匹配条件：

1. 决策导向探查；
2. 通用回应信息探查，即广义 Jensen–Shannon 散度；
3. 随机安全探查，匹配候选支持、机会成本、窗口和实际探查预算；
4. 无探查适应，保留相同网络与辅助计算，但不改变 actor 动作。

另把**适应前骨干**直接作为不增加训练成本的匹配对照，单独评估其 self-play 和 cross-play。它回答整个适应层相对于合格骨干是改善还是破坏协作；四个适应条件之间的比较回答探查控制器贡献。

决策导向探查的最终 checkpoint 另运行一个不重新训练的**回应屏蔽部署对照**：三个相关实验组在候选探查前使用完全相同的被动官方历史和被动信念更新；探查后按 §3.4 的 `P_mask^(p,t)` 保留原始局部观测和任务转移，并从屏蔽组的信念接口、共享延续控制器及循环状态写入中删除当前候选的注册回应坐标及其全部非官方显式别名。它与完整控制器的配对回报差估计注册回应通道的增量使用效应，而不是全部伙伴行为信息的价值。该对照回答部署时的通道贡献，不替代决策导向探查与无探查适应之间的独立训练主比较。

四个适应条件使用相同伙伴家族、家族内成员日程、席位与环境随机数、总环境步、优化更新数、预拟合预算和评估日程。主比较必须独立完成适应训练和部署校准；只在同一个 checkpoint 上切换控制器只能回答部署时贡献，不能回答训练数据分布是否被探查改变。

随机安全探查不能在看到完整方法的实际探查次数后事后配平。它的候选支持、安全门、回合上限、时间窗口和触发概率都在校准数据上预先冻结；正式训练只报告最终实际次数和成本差异。

两个公开布局都固定使用项目中已记录的官方环境配置：局部观察范围 `agent_view_size=2`、随机起点、成功交付提示、负奖励、400 步回合、交付后重新抽取配方，以及温度 1 的随机分类动作采样。具体配置文件及其哈希值在运行前绑定；任何环境参数或行动规则变化都产生新的实验版本，不能与已发表汇总值直接混排。

每个条件产生 10 个最终策略。对每个条件评估：

- 10 个 self-play 配对；
- `10×9=90` 个有向 cross-play 配对；
- 每个配对 500 个 400 步回合；
- 有向配对已经覆盖主体智能体与伙伴的位置方向，不再重复乘二。

所有主结果使用官方原始回合回报。若探查动作已在环境回报中付出成本，不再二次扣费。另报告正确交付、错误交付、配方指示成本、探查次数和推理延迟。

### 6.3 确认性终点与统计单位

唯一确认性终点是 Test Time Simple 上

`决策导向探查的平均 cross-play 回报 − 无探查适应的平均 cross-play 回报`。

同一外层训练单元、同一有向配对和相同回合随机数形成配对比较。由于同一个训练单元会同时出现在主体和伙伴位置，90 个配对不能当作独立样本，也不能把行、列 seed 分开抽样。主区间使用训练单元节点重采样：每次对 10 个训练单元索引有放回抽样一次，所得计数同时作为该单元在主体和伙伴位置的权重，只用 `i≠j` 的原有有向配对重算均值；少于两个不同训练单元的重采样按下一预生成随机键重抽。固定使用 9,999 次有效重采样和运行前登记的随机种子；这样保留同一策略跨两种位置造成的成对依赖。

10 个外层训练单元首先服务于官方协议可比性，不自动保证足够统计功效。主张成立要求配对差异的 95% 训练单元节点重采样区间下界高于 0，并且点估计达到运行前按一次正确交付的回报尺度冻结的实际意义门槛；区间过宽时只报告不确定，不把“不显著”解释为等效。

按以下固定顺序读取结果：

1. 决策导向探查对无探查；
2. 决策导向探查对通用回应信息探查；
3. 决策导向探查对随机安全探查；
4. self-play 非劣化、探查次数和成本。

Test Time Wide 使用完全冻结的方法、阈值生成规则和统计代码做方向复现，不在看到 Simple 结果后重新选择终点。

held-out 伙伴族面板与官方 `10×9` cross-play 主终点分表报告。面板先在每个具体伙伴内汇总配对回合，再在伙伴族内等权汇总；伙伴族是固定评估分层，不把同一族的多个 seed 当成多个独立族，也不把少量预注册伙伴族外推成所有可能生成机制的总体结论。H3 的伙伴族部分要求每个预注册 held-out 族上的配对回报差方向均为正，并同时报告区间；它不是新的 Simple 主终点。

### 6.5 最小机制分析

公开基准只保留三个必要分析：

- 评估时冻结伙伴概率为均匀分布，检验在线更新是否承重；
- 使用 action-augmented 输入，衡量显式伙伴动作信息的诊断参照；
- 把伙伴条件价值头替换为通用回应信息分数，检验决策权重是否承重。

完整后验状态重置、身份分类器、瓶颈维度、坐标剪枝、隐藏马尔可夫模型和粒子滤波器不进入最小主实验。它们只有在主效应成立后才可能作为支持性分析。

### 6.6 Hanabi 独立领域验证

Hanabi 不是 OvercookedV2 的附加布局，而是 H3 的独立领域证据。迁移前固定四项对应关系：候选探查必须是 Hanabi 中合法且会改变任务状态的动作；伙伴回应必须由主体在官方协议下可见的信息确定；任务成本使用同一注册回应通道使用/屏蔽对照，而不是另换成通用互信息奖励；安全事件和风险上限按 Hanabi 规则单独定义，不能照搬“错误交付”。

Hanabi 至少比较决策导向探查、通用回应信息探查、随机安全探查和无探查，并使用预注册的未见伙伴策略集合。H3 的 Hanabi 端点是决策导向探查相对无探查的原始任务回报配对差；`J_use−J_mask` 另作注册回应通道是否承重的机制读数。领域特定网络、动作词表和回报尺度可以不同，但注册回应通道增量价值与相对最佳回应屏蔽参照的净收益对象不能改变。没有这一独立结果时，论文只能声称 OvercookedV2 上的方法证据，不能提出一般协作领域结论。

### 6.7 H3 的三个端点和共同判定

H3 不把三个领域或面板的回报直接平均。它预先定义三个同方向端点，均比较“决策导向探查减匹配无探查”的原始回合回报：

1. `Delta_Wide`：Test Time Wide 的平均配对 cross-play 回报差，使用与 Simple 相同的 10 个独立训练单元、90 个有向配对和训练单元节点重采样；
2. `Delta_heldout`：在固定 held-out 伙伴族面板上，先对每个伙伴求配对回报差，再在族内等权、最后在预注册伙伴族之间等权得到的差；主体训练单元和伙伴策略是重采样单位，伙伴族保持固定分层；
3. `Delta_Hanabi`：Hanabi 预注册未见伙伴集合上的平均配对回报差；至少使用 10 个独立主体训练单元、两个从未进入开发流程的伙伴生成机制且每个机制至少四个冻结策略。伙伴生成机制保持固定分层，主体训练单元和伙伴策略是重采样单位。每个有向配对的回合数由看不到结果的回报界或精度分析冻结，不能根据观察到的效应追加。

Wide 沿用 §6.3 的 9,999 次训练单元节点重采样。held-out 和 Hanabi 各使用 9,999 次分层重采样：每次有放回抽取主体训练单元，并在每个固定伙伴族或生成机制内有放回抽取伙伴策略，再按上述等权规则重算端点。三项都使用运行前登记的独立随机种子和单侧百分位下界。无效回合按预先生成的替补随机键成块替换；缺少 checkpoint、整项策略配对或预注册伙伴族时，不插补，直接把对应 H3 端点记为不可裁决。

H3 的名义错误率预算固定为 0.05，其中 `gamma_cal=0.005` 分给区间方法的运行前校准，剩余 0.045 在三个科学端点之间等分。因此每项端点使用名义单侧错误率 `alpha_H3=0.015`，报告 98.5% 单侧下界。百分位重采样在 10 个训练单元下没有自动的有限样本覆盖保证，因此在生成任何 H3 确认性数据前，必须冻结一套零效应生成器。该套生成器至少覆盖：回报近似对称且各训练单元方差相同、回报偏斜并含大量零值、训练单元或伙伴族之间方差不同、同一训练单元参与多个配对所产生的强节点相关；每种生成器都保持正式协议的回报界、训练单元数、伙伴分层、完整配对结构和零平均处理效应。

对每个生成器和每个 H3 端点独立生成 10,000 份零效应数据，并在每份数据上原样运行正式的 9,999 次重采样和下界判定。记预先登记的“生成器 × 端点”组合总数为 `M_cal`，单个组合的误报次数为 `F`。对每个组合计算置信度 `1−gamma_cal/M_cal` 的单侧 Clopper–Pearson 精确上界；这里的 Clopper–Pearson 上界是根据有限次二项误报计数给出的保守概率上限。由并集上界，全部组合的误报率上界同时有效的置信度至少为 `1−gamma_cal=99.5%`。只有所有组合的该上界都不超过 `alpha_H3=0.015`，三项百分位区间才取得预注册确认性分析资格。对登记的零效应套件，错误授予这项资格的概率至多为 0.005；若真实端点另外满足各注册区间误报率不超过 0.015 的覆盖假设，三个科学端点的错误率之和才至多为 0.045。有限模拟本身不能证明真实 Wide、held-out 或 Hanabi 数据律满足该假设，因此不得把 `0.005+0.045=0.05` 写成无条件的真实数据总体错误率保证。生成器参数与代码哈希、`M_cal`、`gamma_cal`、10,000 份数据的随机种子、9,999 次重采样的按数据集索引派生规则和判定脚本哈希都须在 H3 数据生成前登记。任一组合未通过时，百分位区间不得用于支持 H3，H3 记为不可裁决；不得查看 H3 结果后调生成器、改置信水平或用同一批数据更换区间方法。这项有限套件校准是对已登记依赖结构的压力检验，不构成对所有可能回报分布的有限样本覆盖定理；公开结果必须把三个下界标为名义区间。只有

`LCB_Wide>0`、`LCB_heldout>0` 且 `LCB_Hanabi>0`

同时成立时才支持 H3；不得用一项大收益抵消另一项失败。held-out 面板还要求每个预注册伙伴族的点估计均为正，并完整报告族别区间。任一项不满足时，H3 不成立，结论缩小到实际通过的范围。

## 7. 结果解释边界

| 观察结果 | 允许结论 |
|---|---|
| 决策导向探查优于无探查、通用信息和随机探查，H2 通过且注册回应通道效应为正 | 支持“按决策相关性选择探查并使用注册回应通道能提高协作” |
| 决策导向探查回报提高，但 H2 或注册回应通道效应未通过 | 只能声称该完整系统提高回报，不能归因于忽略价值无关信息或使用注册回应通道 |
| 完整系统回报高，但决策导向探查不优于无探查 | 收益来自骨干、伙伴池或适应训练，不能归因于探查 |
| 决策导向与通用信息相同 | 没有证据表明价值加权比一般伙伴辨识更好 |
| 受控价值无关条件仍频繁探查 | 方法没有做到忽略身份或风格信息 |
| 只有 action-augmented 版本有效 | 结论限于信息增强协议，不是官方观测下的结果 |
| Simple 有效、Wide 不复现 | 结论限于单一布局，不能声称一般零样本协作改进 |
| 校准中没有安全探查候选 | 当前候选集、过滤器和控制器没有找到可利用机会；不得靠事后降阈值制造探查，也不得扩大为整个基底无机会 |
| 合成理论成立、公开基准主效应为空 | 理论对象存在，但未转化为实际协作收益 |

低身份分类准确率只能表述为“在预先固定检测能力和等价界内未发现明显身份信息”，不能证明表示中绝对不存在身份指纹。

## 8. 当前实现与本方案的差距

截至当前项目记录，现有方法契约 v2 已实现：循环 Independent Proximal Policy
Optimization 骨干、独立训练 seed 的伙伴池要求、伙伴条件回应头、在线伙伴概率、广义
Jensen–Shannon 散度探查、回应头预拟合和无探查阈值校准。2026-07-13 的静态修订又加入了
伙伴条件折扣原始回报头和一个有限伙伴原型上的两步动作代理量。这个代理量只按伙伴原型、
回应记号和下一原子动作求和；它没有任务转移 `x`、完整隐藏执行状态，也没有实际运行
`B_use`、`B_mask` 和共享延续控制器的成对分支。因此它明确登记为
`finite_prototype_two_action_surrogate`，只允许诊断，不能称为本方案的 `J_use−V_mask`。

当前仍没有实现本方案主方法所需的**伙伴条件一步转移—回应模型**、**同一任务转移与随机流
上的回应使用/屏蔽分支**和**可用于正式读数的成对顺序价值估计器**。因此：

- 现有广义 Jensen–Shannon 散度控制器降为正式基线；
- 旧归一化动作相对价值集成分歧降为次要历史消融；
- 有限伙伴原型两步代理量只能用于接线与近似诊断，训练器和评估器均拒绝把它作为
  `decision_focused` 正式条件；
- 正式无探查条件和通用回应信息基线在没有实际触发探查时保留 actor 原动作；伙伴条件价值头
  不再暗中覆盖无探查参照。正式阈值校准必须绑定摘要和逐决策账本内容哈希，并从 500 局、
  50000 个早期决策点重新核对零探查、角色与伙伴平衡及冻结分位数；`pending` 摘要哈希不能
  启动正式训练；
- seed 101 的旧适应运行使用同一训练 seed 的时间快照、固定旧阈值且探查为零，只是诊断记录，不能进入新的确认性十单元结果；
- 当前没有可进入本方案主表的多 seed 科学结果。

**（2026-07-13 裁决更新，2026-07-13 静态复核后修正）** 当前最高价值动作仍是先测量可利用的伙伴信息，但测量对象改为 [PATH_C_OPPORTUNITY_AUDIT_SPEC.md](PATH_C_OPPORTUNITY_AUDIT_SPEC.md)（R015）定义的官方观测控制器：注册回应通道的增量使用效应、相对最佳回应屏蔽参照的净收益，以及可选的完整信息保守上界。R015 不再把评估器完整状态当成学习器输入，也不声称固定短视控制器是全类上界。

用户在 2026-07-13 明确授权把优化后的方案反馈到静态代码，因此先前“R015 读数前不实现
扩展组件”的资源排序已经退休。该授权只覆盖静态实现，不改变运行边界，也不把两步代理量
升级为正式方法。R015 的机器合同现能验证固定支持、正式抽样清单、三组完整配对轨迹、回应
路由、分布无关区间、安全分支证据和一次正式查看。每次咨询还必须由内容寻址的冻结验证器从
官方历史与规划分支重新计算完整候选集、`J_use/J_mask/V_base/V_mask`、安全资格、选择和首次
正分停止。正式轨迹验证还须从冻结主体与伙伴 checkpoint 逐步重算双方动作和循环状态；安全
验证须从官方历史、实际选中脚本和对应支持原型 checkpoint 重放各分支。自报动作、状态、
分数或安全结果均不能单独通过。上述验证器及正式控制器目前仍是 `pending`；裁决代码只完成
冻结与验证接线，不生成官方观测过滤器、相容完整状态分支或正式 `J_use/J_mask`。普通负结果
只否定冻结支持上的注册单次探查控制器；没有经证明的完整信息上界时，不关闭整个
OvercookedV2 基底。

## 9. 成功标准

一份达到顶会水平的结果必须同时满足：

1. Test Time Simple 的匹配确认性比较支持 H1；
2. 受控价值无关条件支持 H2，而通用回应信息基线显示预期的过度探查；
3. Test Time Wide、预注册 held-out 伙伴族面板和 Hanabi 的冻结验证共同支持 H3；
4. 所有训练与伙伴池成本完整报告；
5. 官方观测结果与 action-augmented 结果分开；
6. 理想信息价值目标与顺序任务的受限注册回应通道之间有明确映射，未证明的继承关系由 H2 和配对部署对照检验；
7. 任何机制措辞都不超过实际通过的审计范围。

如果只满足公开基准高回报而没有匹配探查效应，本项目仍可报告一个有竞争力的协作系统，但不能把贡献写成决策导向主动伙伴推断。

2. **Hanabi 为必需第二领域。** Test Time Wide 只承担 OvercookedV2 内部复现；投稿级跨领域主张另需 Hanabi 上的独立证据，实验对象见 §6.6。
3. **评估必须包含 held-out 伙伴族。** 除不同训练 seed 外，须纳入来自不同训练算法、目标或约定生成器的伙伴；否则零样本主张只是训练原型集合内的插值。held-out 伙伴族使用独立评估清单，不进入训练原型集合、过滤器支持、校准或 R015 支持；进入 R015 支持的伙伴不能同时称为 held-out。
4. **定位改写为面向协作的信息价值方法。** 涌现目标保留为表示约束（骨干只接收共享
   critic 的时序差分梯度）与证伪检验（价值无关身份不变性），不再作为公开贡献主张。

先前证据的权重认定照录：D1 两轮是强不利证据（直接演示了公共状态退化，但在前身基底）；

Double Q-learning，使用 seed 201/202；第一族仍为 3000 万环境步循环 Independent Proximal
