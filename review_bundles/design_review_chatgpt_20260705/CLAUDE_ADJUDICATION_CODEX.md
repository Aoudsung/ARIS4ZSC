## 1. 三处最有价值的新发现（codex 独有）

### [09]（致命级，虽 codex 标重大）— Q 接口使"均匀信念→零优势"，与 §2.2(c) 机制故事直接冲突

**Claude 核实**（`factor_q.py`）：
- L264 `centered_belief = belief - masked_uniform(mode_mask)` —— 信念以**中心化**形式进入；
- L299-302 `weights = residual_weight([obs; factor; option]); raw_adv = (weights * centered_belief).sum` —— 在因子内**线性于中心化信念**（权重是状态/因子/选项的 MLP，信念本身线性）；
- L333 `q_values = q_base + adv_sum`，`adv_sum` 跨因子**相加** —— 因子局部加性确认。

**推论**：均匀信念（=开局状态，也=OOD 回落状态）下 `centered_belief ≈ 0 ⇒ adv ≈ 0`。即
**信念在不确定时对 Q 的贡献恰好为零**，此时决策完全由 belief-independent 的 `q_base`
驱动。而信息采集价值（VOI）本质是信念熵/展开的**非线性**泛函，在均匀点梯度为零——
这个线性中心化接口**结构上无法表达"因为我不确定所以去试探"**。

**为何是全案最深的一击**：它把 rev3 §2.2(c)"不确定状态训练-部署共享"从"薄弱"直接变成
"与实现自相矛盾"——共享的那个不确定状态，恰是信念通道零贡献的状态；agent 在该状态做
什么全看 q_base，而已有诊断（EXPERIMENT_LOG 07-05：置零信念平移 Q 但"等待"仍排最前）
正说明 q_base 默认让位。**换 GRU→BayesMode 不触碰这个接口**，所以 U2 大概率救不了死锁
——这与 rev3 自己的 §6.1-1 override 门指向同一根因（控制侧），但 codex 给出了接口层的
机制解释。裁决：**升级为致命，且是 override 门之外必须加的一个表达力检验**（codex 建议的
AND/XOR mixed-role toy + uniform-belief probe Q-margin）。若成立，U2 的机制主张需要一个
**非线性信念接口或 entropy/VOI 特征**才可能成立——这可能比 BayesModeFilter 本身更关键。

### [07]（重大，已核实）— 后验温度未约束

SPEC §1 用 `b ∝ b̃·exp(g_θ)`，g_θ 仅 clip 到 [-30,30]、只经 TD 训练。TD 无概率校准压力，
可把 logits 推向饱和。后果：§5.2 的 MI 比值、跨种子对齐、belief-swap 全部被后验尖锐度
（温度）混淆——"角色语义"可能只是被 TD 放大的 logit scale。裁决：成立；G-mech 门须加
posterior temperature/entropy/ECE 审计，且语义指标须在固定温度下稳定才算数。

### [01]（致命，已核实为 rev3 逻辑 bug）— 四子命题 ⇔ 命题 是伪等价

rev3 §3 写"核心命题成立 ⇔ M∧A∧G∧D"。codex 正确指出这是**范畴错误**：D（战胜廉价基线）
是**方法必要性/新颖性**，不是"角色是否正确粒度"的本体成分。真角色世界里可以既"角色是
正确粒度"为真、又存在一个廉价基线也利用了它（D 失败但命题真）；反之四门全过也可能只是
一个 TD 低维状态进度变量有效（命题假）。这是我重构时为了"干净"过度收紧引入的缺陷。
裁决：成立；`⇔` 改为 outcome-to-claim **matrix**（各子命题→可支持的主张档位映射），D 移到
"方法必要性"维度，不进粒度命题的充要条件。

## 5. [09] Q 接口决策（2026-07-05 收敛，取代先前的分支阶梯）

**决定：rev4 不动 Q 接口。**

依据（已核实）：配置 `adv_bound = base_bound = 15`——信念通道授权额度与基础价值相等，
未被结构性饿死；诊断显示信念平移 Q ≈20.5 却翻不动"等待"排序 = **有等量授权、动了量、
仍不翻 argmax = 授权未用满**，属信用/优化签名而非表达力天花板签名。叠加 probe-then-commit
本可表达、本布局第二轴（bottleneck）是可观测导航而非信念 ⇒ 接口非当前绑定约束。改接口
= 折掉承诺三（因子局部可加 → 干净归因），代价不划算。

**单一下一步：先跑 override 门（rev3 §6.1-1）**——高让位证据状态强制接管一步，量回报
vs 等待。它在整个 U2 问题的上游（不只是接口）：无正回报 ⇒ U2/接口/任何方法层改动皆
白费、转 population；有正回报 ⇒ 问题定位到控制学习，届时才有证据谈接口 vs 信用。
**不预先规划 override 之后的分支**——那一个 bit 到手再定，现在排后续分支即是猜。

（先前此处的"三 sanity gate + 五分支接口阶梯"已废弃：它把决策推迟成 if-then 阶梯，
违背"先做能消除最大不确定性的那一件事"。override 门单独支配那整套。）
