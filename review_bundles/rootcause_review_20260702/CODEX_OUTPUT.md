Judgment: P1 does not make parity a mechanical theorem. ## Q-F advisory

In principle, TD-only plus purely behavioral evidence can learn factor inference after de-oracling and belief persistence, but only under identifiability and coverage: value-critical modes must induce separable local evidence through task-valid actions, the replay must include those states/actions with sufficient support, and the belief state must be Markov enough for control. The proposal's assumptions allow this; the current implementation did not yet provide the necessary clean test.

The discriminating test is not label accuracy. Use a de-oracled benchmark with hidden factor recombinations, report return/oracle-gap closure after diagnostic actions, and run belief-swap/factor-deletion/shuffled-route ablations. If ARIS improves return and oracle-gap closure while shuffled routes or deleted value-critical factors selectively degrade it, TD-only behavioral inference is supported. If flat belief matches ARIS, the claim narrows to belief usefulness without factor-local routing.
