== DEFECT CLASSES (anchored) ==
[C4 sentinel aliasing] Anchor: P3 CE sentinel zeros. GENERALIZE: any place a sentinel/default
(0, 0.0, -1, None, NaN, empty list) can be confused with a legitimate measurement downstream:
CE estimation cells, support/weight accounting, metrics fields absent-vs-zero (e.g., a run with no
episodes vs a run with zero deliveries), None→0 coercions in aggregation, NaN silently absorbed by
max/mean/clip, JSON round-trips turning NaN into null, missing keys defaulting inside .get()
chains, division-by-zero guards that substitute a value indistinguishable from data.
[C5 metric semantics] Anchor: F9 team-vs-ego conflation masking free-riding. GENERALIZE: for EVERY
metric that feeds the preregistered tables (headline: held-out ego_correct_completion_rate;
co-primary: terminal competence rate; secondary: throughput, time-to-complete, ego/partner splits,
wrong-delivery, sole vs assisted counts, team_delivery_episode_rate): verify (i) the right agent is
credited (ego vs partner attribution at the event level — trace event_extractor→metrics); (ii) the
denominator is what the table assumes (episodes? attempts? only-successful-episodes? do guard-fail
or crashed runs silently vanish from means instead of being counted per the preregistration?);
(iii) rates cannot exceed bounds or double-count (delivery counted per event vs per soup);
(iv) train-partner greedy_validation fields cannot be mistaken for held-out fields downstream
(naming/labeling in metrics.json and eval outputs); (v) checkpoint_selection: "best" selected by
greedy return — confirm selection criteria can't pick a checkpoint whose eligibility gates failed,
and selection metadata records what the tables need.
[C9 artifact/orchestration integrity] Anchor: the orchestrator local-bug data loss. GENERALIZE

partition-mismatched artifacts, baseline cache correctness (evaluate_aris: key must include EVERY
input that affects the cached value — env subset, reward payload, partner identity, episode count,

conditions e.g. zeroed vs inferred if baselines could differ), replay.npz partition safety, tar/
sync manifest completeness (provenance.py), and the S7 quarantine: verify no formal-path caller
can reach collect_option_replay_batched (grep all callers; the red line must be structural, not

[C10 numerics/units] Anchor: reward-scale drift history (reward_scale_verified gate) + two
gate-caught graph/config objective mismatches. GENERALIZE: env-step vs option-step confusion
