# Retired DEPI v8 implementation evidence

This directory preserves the complete superseded DEPI v8 method package,
experiment applications, configurations, workflow and test suite. They are
historical artifacts, not active DELTA-ZSC entry points and are excluded from
package discovery. The active method lives in `src/delta_zsc/` and is invoked
only through `python -m experiments.overcooked_v2.delta_zsc`.

Historical L0 analysis utilities are retained under `analysis/`; they are not
imported by the active package or cited as evidence for the unified method.
