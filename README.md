## One principle

A partner history is decision-relevant only when it changes the counterfactual
value of the ego's available actions.  Unified DELTA represents this with one
exchangeable latent coordination mode `z_t` that jointly generates:

1. the next legally observable partner response;
2. the empirical all-action continuation-value signature available only during
   training.

The same latent mode must explain both emissions.  Training therefore uses one
joint marginal likelihood rather than a collection of independently weighted
auxiliary losses.

```text
legal local history
    |
    +-- task-only observation ----------> recurrent task state x_t
    +-- current partner planes ----------> memoryless geometry r_t
    +-- observable event counts ---------> analytic Beta statistics u_t
    +-- response likelihood + T ---------> categorical belief b_t
                                               |
privileged CRN continuation anchors ----------+
                                               v
                                 component action values Q_k(x,r,u,a)
                                               |
                                 E_b[Q_k] + gamma * exact myopic VOI
                                               |
base policy pi_0 ------------------------------+
                                               v
                       analytic KL-constrained mirror policy pi_DELTA
```

There is one shared base actor/value network and one shared latent model.  No
partner-specific actor, critic, codebook, comparator, generator, separation
network, or auxiliary actor is trained.

## Scientific method parameters

The method section contains exactly three choices:

```yaml
method:
  latent_components: 4
  continuation_horizon: 128
  adaptation_kl_budget: 0.04
```

They define, respectively, latent capacity, the decision-equivalence estimand,
and the maximum policy deviation from the base policy.  Network widths,
optimizer values, sample counts, and evaluation budgets are engineering or
statistical-design fields, not additional mechanisms.

## What was removed

The unified path removes the earlier patch chain:

- learned capability GRU and consistency/prediction/variance/covariance losses;
- response, signature, rank-hinge, component-signature, posterior-KL,
  actor-target, and pair-separation weighted objectives;
- matched-pair comparator, probability thresholds, and separation margin;
- context dropout and an auxiliary actor transaction;
- fixed sticky-probability sensitivity matrix;
- stale anchor replay and stored posterior pseudo-labels;
- ten independent paper-claim gates and the 14-variant development grid.

Observable capability is now an analytic Beta posterior.  Transition dynamics
are learned by maximum likelihood.  Counterfactual anchors enter as a
heteroscedastic decision emission, with replica uncertainty included directly
in the likelihood.  Policy adaptation is the closed-form KL mirror solution.

## Training

Training data are always generated by the base policy `pi_0`.  This gives two
clean estimators:

1. base PPO is exactly on-policy;
2. the latent model is trained from response sequences and sparse decision
   anchors collected under the same base continuation policy.

The two estimators have separate parameter trees, optimizers, and Adam moments.
The latent model cannot change the training data policy.  At deployment, its
posterior decision values improve the frozen base policy analytically.

Example:

```bash
python -m experiments.overcooked_v2.delta_zsc train \
  --config experiments/overcooked_v2/configs/delta_unified_simple_development.yaml \
  --partner-manifest /absolute/path/partner_manifest.json \
  --variant joint \
  --seed-index 0 \
  --run-kind development \
  --output /absolute/path/run
```

Variants are naturally nested:

- `base`: base PPO only;
- `response_only`: response latent model, no decision-conditioned adaptation;
- `joint`: joint response-decision latent model with passive adaptation;
- `full`: the same joint model plus exact myopic Bayes value of information.

`joint` and `full` can share one trained parameter bundle because VOI is an
analytic deployment operator, not another learned module.

## Evaluation

```bash
python -m experiments.overcooked_v2.delta_zsc evaluate \
  --deployment /absolute/path/run/final_deployment \
  --partner-manifest /absolute/path/confirmatory_manifest.json \
  --output /absolute/path/evaluation

python -m experiments.overcooked_v2.delta_zsc calibrate \
  --deployment /absolute/path/run/final_deployment \
  --partner-manifest /absolute/path/calibration_manifest.json \
  --output /absolute/path/calibration

python -m experiments.overcooked_v2.delta_zsc evaluate-causal-belief \
  --deployment /absolute/path/run/final_deployment \
  --partner-manifest /absolute/path/confirmatory_manifest.json \
  --output /absolute/path/causal
```

The paper has three preregistered hypotheses:

1. Full DELTA exceeds the strongest external baseline;
2. joint response-decision training exceeds response-only training;
3. the correct belief has positive source-world decision value over a
   task-matched shuffled belief.

All calibration, component usage, entropy, resource, and representation
measurements remain diagnostics.  They cannot be promoted into extra
contributions after results are observed.
